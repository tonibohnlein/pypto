# 旋转令牌历史检查点

本检查点从 `a49405511` 扩展单区域旋转槽流的标量 RFC 令牌历史。
有限及规范重置序列保持支持。旋转跨区域、嵌套令牌及生产协调仍未迁移，
因此仅完成第二里程碑的单区域部分。

距离三的源携带三个 completed 初值，同时 yield
`[current, previous_1, previous_2]`。消费者在
`iv > start + 2*step` 下等待第三个历史。降低按变量身份迭代解析方程，
保留管线、原始坐标及调用，不重新进行存储需求约简。旧最终结果不能冒充
最后源访问；短于历史的调用返回 completed。循环历史及错误守卫明确拒绝。

物理降低完成且存在 SET/WAIT 后，复用生产路径的 `SyncOutcome` 所有权属性。
这只证明给定令牌协议已被降低，不证明任意手写令牌覆盖存储依赖。空计划不
伪造标记，分配算法、可用 ID、硬件规则及默认生产流程均保持不变。

独立检查原始访问、实际覆盖边、四类事件查询、边界选择器、令牌/标志的完整
负载顺序、匹配、无环及消费后再发布。测试包含零/短/尾访问、非零起点、非单位
步长、非互素步幅、互素槽族、携带变量重排、序列化、缩短现有长历史，以及
错误守卫、循环历史和非空旧结果跨界的拒绝。C++ 检查保留下游 autosync 启用。

标量历史空间 H 为每个源最大活动距离之和。固定距离时不随 K 增长，不保证
对二进制编码周期紧凑。周期二和三的独立族保留五个携带值，而非联合周期表。
既有导入器的空循环代表访问检查、无标记时的委托槽限制及原生 16 槽限制仍在。

三个交错主机计时对中，K=4/7/1024/1000000 的物理 PTO 与原生产路径逐字相同。
K≥7 的静态 SET/WAIT 均为 9/9、算术操作为 76；令牌阶段中位时间约 0.9–1.0 ms，
为直接路径的 2.3–2.6 倍。这是主机开销，不是加速或设备证据。小例使用方向 ID
0–2，但本任务没有改变目标资源目录。

广泛回归通过 981 项（28 个既有警告），最终重建的聚焦回归通过 93 项，
包括互素历史和 C++ 生成。三类审查均接受此限定范围，仓库检查已通过。
