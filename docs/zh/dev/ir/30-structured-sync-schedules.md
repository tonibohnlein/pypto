# 经限定的结构化同步调度

基线为 `868fdd471`。精确需求分析、token 匹配、物理分配和硬件豁免保持不变。
`LowerSync` 在创建标量语句之前，从已有的已分配命令描述中提取满足条件的边界命令。
它不会重新运行同步分析，也不是对已物化标量代码增加一个优化层。

## 支持范围

首个构造支持已知非空、常量边界、正步长、最终增量可表示且至少执行两次的顺序
INDEX 循环。循环不得有携带结果、特殊属性、定义、未知副作用或嵌套控制。
已有证明、共享无条件命令切点的初始化/累加分支可以保留。
零次、单次及不支持的循环沿用原有降低。

只有首个载荷的输入切点和最后载荷的输出切点可以移动命令。入口提取要求命令在
所有非首次迭代都不执行；出口提取要求它在所有非末次迭代都不执行。
现有算术分析器在包含其余 IV 值的区间上证明这一点；证明失败表示未知，而非不活动。
非单位步长不需要枚举迭代。

从相应边界扫描命令序列。前方（入口）或后方（出口）的命令若没有同时提取或被证明
在边界迭代不执行，就阻止移动。组内顺序保持不变。提取后的 IV 替换为原始边界常量，
未知的外层谓词保留。第二个载荷前的 WAIT 不能跨越第一个载荷。

## 正确性与所有权

- 被移走的命令在所有其他迭代都不执行。
- 边界迭代上不跨越任何执行中的命令或载荷。
- 严格限制的循环体不引入 SSA 定义或隐藏标量副作用；捕获值支配循环。
  替换 IV 消除了唯一改变作用域的值，原始分支控制保留。
- 非空循环及其外层条件保持原位；每次外层调用都保留计数器重置语义。
- 操作、方向、ID 和有序命令重数不变。单载荷循环的入口和出口也使用独立清单。
  匹配与复用继承自完整建模载荷/命令轨迹不变，而非新的完成边界假设。

描述所有者保持不可变，接受的循环使用局部切点覆盖；拒绝时保留原描述。
不复制载荷或循环，不重建分配、token 身份或存储坐标。

## 成本及被拒绝的方案

候选必须保持静态命令数、减少 guard 数且不增加受影响描述的表达式出现次数。
这不是序列化 IR 或 C++ 字节数的通用上界，完整输出另行测量。
描述级 guard 求值不增加：删除边界测试，剩余外层谓词至多计算一次；循环头不变。
移动谓词作用域可能影响后续标量值共享，因此最终标量操作成本是测量结果，而非通用推论。
计数包括循环体/切点检查、描述访问、拒绝候选和前后控制大小，不随迭代数展开。
已有算术分析器的表达式证明成本单独计入限制。

早期首/中/末阶段复制实验在全部 28 个用例上被拒绝。大规模 gate/up 的估计内部表示
从 1,092 增至 2,576 节点。该实验不在生产路径中；阶段复制或符号族合并需要独立契约。

## 验证

`structured-sync-control.json` 保存源码、工具、输入身份、命令、输出大小及轨迹比较。
合成测试覆盖非单位步长、负起点、零/单次、外层跳过、重置、命令组、移动障碍、孔洞及
未知作用域。合成测试只验证降低；生产用例的独立访问/命令检查验证建模覆盖、匹配、
无环和因果复用。

guard 代码过多并未否定精确需求分析：这些用例已经保留紧凑数学结果，本修复针对命令
如何利用原循环结构。它不构成通用结构化调度定理。本次仅主机验证，不证明原生调用
入口/返回语义，也不提供新的设备性能结论。
