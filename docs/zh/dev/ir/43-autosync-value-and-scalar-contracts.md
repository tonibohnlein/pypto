## A：活动前缀值域规范化

`NormalizeBufferActiveDomains` 是 `SelectBufferIRFunctions` 使用的内部候选构造器，
不是新 pass 或分析后端。它区分保证定义的值通道、下游需要的通道和元数据观察者。
过宽的结果类型标注本身不能证明全部通道有定义。

当前家族支持 FP32 逐通道操作、已确认的行归约、连续向量轴映射以及直接的计数循环
ADD 累加。完整初始化种子可以限制到与回边相同的运行时前缀，但边界必须已经就绪、
在循环入口可见且在循环内不变。每个分量只保留一个命名的前缀；不相关边界、一般并集、
依赖内部计数器的边界及未知生产者保持不可用。原操作有效性契约仍要求活动范围位于
物理容量内；不引入 `r = 8` 等调用者假设。

```text
完整初始化种子 -> 显式前缀别名 -> 计数循环携带值
部分行 -> 行归约 -> 连续行向量前缀 -> ADD
循环结果 -> 原逐通道算术 -> 列向量前缀
部分矩阵消费者 -> 原部分范围输出存储
```

保留产生种子的载荷。循环初始化改为指向相同已初始化字节的显式前缀别名；
零次循环保留合格初始化值。零活动行使用已有空操作守卫。
物理形状、行距、算术、原守卫和次数不变。若完整输出存储观察到仅定义前缀的结果，
则拒绝规范化，而不是缩小存储。这区分了可接受的后归一化结构和 `rms_recip`
完整输出的剩余义务。

`tile.set_validshape` 共享存储和元数据。旧完整使用依赖已有动态所有者逐使用点恢复及
存储/活跃性契约。未知元数据观察者，包括嵌套调用、调用/作用域/函数属性和标量循环
初始化，保留原函数。包含 Tile 的聚合元组也拒绝。For/While 初始化在声明位置检查，
包括零次路径；循环体引用不递归重放初始化表达式。

只有完整的普通 Buffer 准入检查全部成功后，才发布不可变候选。后续操作配方、规划器或
描述符失败时保留原函数体，不发布部分规范化的 Functional IR。降低只消费显式的新别名
和类型，不进行第二套宽松值域推断。

### 构造工作

定义/值域索引按语句出现位置遍历，不跟随标量表达式路径。元数据扫描分别缓存普通使用
和观察上下文，并缓存类型身份。反向需求的高度有界：未使用、一个前缀、完整范围。
不支持的交集是不可用结果，不是空答案。

一次不可变稳定性检查覆盖标量调用、算术、元组、投影和元数据。合格表达式原样保留。
未改变类型的 SSA 绑定、函数 ABI 和元数据保持不变；只重新绑定已证明的局部 Tile 声明。
保留标量调用表达式不意味着消除它的语句执行。该设计避免按绑定代数重复扫描，也避免
基础 mutator 对共享 TupleType 和 IterArg 初始化图的递归树展开。具体语句/表达式处理器
记录实际分派工作；仅在通用入口计数会漏掉内部 functor 调用。

只读 `testing.normalize_buffer_active_domains` 适配器返回同一候选及可选请求级计数。
`changed` 只表示规范化，不表示完整 Buffer 准入或可执行所有权。计数在每次请求重置，
不是证明状态或缓存。

## B：本地 UB 标量载荷与 Tile 到 Buffer 桥接

选定的 A2/A3 AIV 契约接受稠密二维 Vec FP32/INT32 上、静态有效范围内常量坐标的
`buffer.read` 和 `buffer.write`。扁平原生索引必须适合 uint32。其他核、类型、动态坐标、
未证明元数据或缺失布局来源均保持不可用。

它们是正常的 PIPE_S 内存载荷。read 具有读效果和标量 Value 结果；write 写入目标。
选定的 `pto.tgetval`/`pto.tsetval` 使用 UB GetValue/SetValue 类型化访问，不访问 GM DCache，
不需要隐藏的异步工作区或标志。选定实现保证原阻塞标量结果就绪；仅有 Value 结果声明
不能提供该原生保证。

共享 Tile 桥接保留原 read SSA 定义与插入位置。分支、地址及循环条件消费实际值。
缺少直接 SSA 绑定的丢弃或嵌套 Tile read 在降低前委托，不构造虚假值。
无论是否绑定返回值，Tile write 都修改原存储。返回 Tile 是别名，不是新分配或副本；
完整 MemRef/窗口，包括槽坐标，必须一致。旧别名继续观察到修改。

### 静态物理行距与元数据

原生标量索引采用 `row * physical_columns + column`。窄窗口可能继承更宽的父行距，
因此仅凭描述符形状不足。现有放置/窗口清单必须证明稠密物理行距。
完整宽度的重叠窗口可接受；继承不匹配行距的窄窗口和缺失证据的借用句柄拒绝。
验证、分析、插入、实际令牌降低和代码生成要求相同前提。
ALL 屏障不能修复错误的地址计算。

另一别名把所有者提升为运行时元数据后，原静态点仍可使用现有静态描述符桥接，
恢复原有效范围和物理行距。这不接受真正动态的点，也不从不可用描述符推断精确访问。

### 独立命令模型修正

有界 oracle 为后续 S 指令和实际标量值/控制消费者加入原生标量完成顺序，
不会把每个标量访问变成其他管线的围栏。读写仍需要适用的跨管线服务。
测试覆盖故意遗漏的 S 到 V 写服务、独立管线、跳过分支、空循环及最后一次 false while
测试。匹配、无环和消费先于重新发布由实际命令检查，与建模字节冲突覆盖分别验证。

### 未修改的完整 Qwen 主机捕获

在固定的 PyPTO-lib 源码上，原两层、序列长度 128、batch 1 捕获生成全部 32 个叶 C++
文件。显式 conservative-prefix 策略报告 79 个执行域：47 个已观察的任务控制所有者、
17 个已验证 PyPTO 叶和 15 个委托叶。`post_rmsnorm` 新增为 PyPTO 所有；此前是
16 个所有和 16 个委托。包含全部阶段的 6.690 秒编译时间仅为一次描述性测量，
不是单独分析时间或加速证据。

## 结论边界

| 已建立结果 | 剩余前提或限制 | 合适表述 |
| ---------- | -------------- | -------- |
| 合格前缀规范化保留观察通道和原控制 | 未支持生产者、观察者和聚合逃逸拒绝 | 可复用输入/原生元数据修复，不是新最小需求定理 |
| 本地标量效果和原 SSA 就绪性进入现有同步服务 | 仅 A2/A3 AIV、静态 FP32/INT32 UB 点及已证明行距 | 合格本地标量实现与有界主机检查 |
| 实际命令独立检查匹配与因果复用 | 现有有限 oracle/原生模型及六个可用 ID | 已检查计划的可行性，不是最小容量或设备正确性 |
| 原两层 Qwen 捕获生成 32 个 C++ 叶；prefix 所有 17 个、委托 15 个 | exact 保留三个所有者；部分导出、效果和控制义务仍未满足 | 改善有界主机覆盖，不代表完整 Qwen 所有权或设备资格 |

INT64 中转、新跨核同步或一般令牌/协议实现。分配、硬件豁免、专家协议及零内部循环屏障
不变。不声称设备验证或设备加速。
