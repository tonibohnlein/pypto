# 规范循环令牌检查点

本检查点从 `0611a9e07` 的有限基础扩展到三个原始矩阵乘示例，包括
`ddr_split_k`，完成首个迁移里程碑的目标示例。旋转历史、嵌套 Qwen 和生产
迁移仍未完成；普通 `RealizeSync` 保持既有实现。

结构化解析器读取实际 record、wait、循环参数、yield 和结果，验证原始
负载切口及首/后续访问守卫。携带值必须从 completed 开始并无条件 yield
当前记录。它保留每次使用的身份、起点、步长及计数器重置；零次循环的
结果仍是 completed。

实际令牌族驱动既有周期前沿计算，不重新提取存储覆盖边。跨区间顺序复用
提取出的既有边界图；`DirectSyncOrder` 向原分配器提供充分的完成到开始
复用证明，发射器使用原始输入。没有私有旁路、新分配策略或容量修改。
结构化分配不声称最少 ID。

独立解释器比较完整负载顺序关系、访问覆盖、匹配、无环性及因果物理复用。
检查包括零/一/多次访问、初始化与累加、非单位坐标、重置、重复等待和
序列化。非规范守卫、非空入口事实、旧历史 yield 和移位记录仍明确拒绝。
零次源循环到活跃区间的 completed 导出有独立回归。

K=2、1024、1,000,000 的衍生例测量静态表示与主机构造时间；只有小实例
进行展开语义验证。首/末端口图对静态端口数可能是二次的，不能将循环次数
紧凑性等同于整体线性编译。

复现命令、最终哈希、测试结果及成对测量见机器可读收据和
[英文检查点](../../../en/dev/ir/19-structured-token-checkpoint.md)。未进行设备
验证；原生访问与调用返回完成性仍是独立前提。

广泛回归通过 947 项（28 个既有警告），最后重建后的聚焦回归通过 218 项，
包括作用域分配、集合阶段和 C++ 生成。四个测量例的物理 PTO 与直接路径
逐字节一致。DDR 保留 15/15 SET/WAIT，三个 K 衍生例均为 33/33。令牌阶段
约 1.4–2.2 ms，为直接路径的 3.1–4.6 倍；没有编译或设备加速结论。
