# 自动同步架构契约

本检查点在扩展符号或注意力区域支持前，加固现有 token 到命令的流水线。
基线为 `0945950aa`，不改变需求生成、物理分配、硬件豁免、协议或生产选择。
基线的设备验证是独立活动。

边界如下：

```text
已限定访问 → 需求分析 → 逻辑完成 token IR
→ 共享逻辑优化/验证 → 实际 token 解释
→ 现有分配器 → 不可变分配方案
→ 已限定命令描述符 → 所选调度与标量绑定方案
→ 物理 SET/WAIT/屏障 IR
```

逻辑 token 描述完成事实；分配方案描述消耗型资源使用；描述符和标量绑定方案描述如何发射
已经选定的协议，不授权改变计算载荷顺序。

## 逻辑阶段所有权

公开 `OptimizeSync` 和生产 `RealizeSync` 均使用 `OptimizeLogicalSync`。
当前服务只验证，不重写。未来逻辑变换应放在此共享服务中，并验证重写后的输出。
生产插入和优化生成的 IR 属于编译器：格式错误是编译器错误，不能转化为交给 PTOAS 的准入拒绝。

IR 边界仍是不可变、非消耗的完成 token。`LowerSync` 解释实际 token 使用，
不会重新计算最小需求来替换已有顺序。逻辑有效不保证能降低；不支持的语言形式明确拒绝。
最终消耗型硬件 ID 是独立资源。

## 已限定命令描述符

构造验证坐标谓词语法和物理同步叶节点。生产另将缓存的谓词变量要求绑定到原始插入点作用域：
标量形参和支配性的启动索引是入口事实，原始循环变量仅在其活动循环内可用。
入口事实在插入点之间共享。重复静态锚点取局部作用域交集；同名变量不等于同一坐标。
任意 SSA 定义不会仅因标量类型而被视为已就绪。

诊断命令片段显式保留调用者提供的就绪契约；可选作用域检查复用生产规则。
未证明的算术禁用可选共享，不代表恒定条件或空条件；生产限定命令时会拒绝它。
有副作用的条件和计算载荷不属于命令描述符。

保留端点域必须具有非空框架，并匹配原始所有者、调用域、区域、循环坐标和合法半开区间。
缺少覆盖不等于空区间。绑定至不同边界时更新谓词要求。区间与余数证明保持独立；
本检查点不引入新的符号域构造。

## 不可变物理分配

现有分配器仅在限定屏障、预留通道和分配颜色时持有可变族记录。成功后将向量移入只能由分配器
构造的 `AssignedSyncPlan`。调度和诊断读取常量引用，不保留第二份族清单。
`AssignedSyncCase` 将不可变分配与可变输出/工作计数分开。

分配对象拥有族记录、原始 IR 句柄、有效方向资源池及原生预留。发射检查原始输入身份、所有者、
目标、调用域以及坐标框架/站点元数据。输入必须在同步的分配/发射事务中保持存活且不变。
保留的诊断句柄不是授权其他输入或后续事务的序列化证书。该边界不重新分配，也不改变复用证明、
容量判定或所选 ID 表。

物理 ID 仍是目标操作属性。逻辑完成 token 非消耗且可以有多个使用者，绝不是已分配 flag。
命令分组诊断明确不属于物理认证。

## 共享标量绑定计划

每个命令森林保留不可变的标量绑定计划，记录原始谓词、作用域内表达式配方、首次使用处的定义
以及标量操作计数。调度成本计算对这些计数加权，并用原始谓词划分活动域；发射消费同一配方，
只在调度选定后分配新的 SSA 名称。两者不再各自重新发现公共表达式。

分支臂具有独立的绑定作用域。定义保持在首次求值位置，不移到循环入口或外层守卫之外。
短路及其他未获限定的表达式不共享。可选结构比较失败时保留合法的未共享构造。

缓存复用仅限本次降低事务。查询比较全部有序不可变根句柄，并记录检查工作；森林改变
（包括父级间隙组合）后重新构建计划。冻结快照使用普通根句柄，避免通过缓存所有者形成环。
语法计划复用不能替代原始切点的就绪性检查。仍先按原始坐标物化，再执行现有克隆/绑定。

## 生产与测试支持的所有权

生产物理降低从实际 token 经 `RealizeDirectSync` 和 `EmitAssignedSyncCases` 开始。
旧公共数学适配器 `RealizePhysicalSync` 与 `RealizePhysicalInvocation` 已删除。
提供需求的用例构造移至 `python/bindings/modules/testing_sync_support.*`，复用同一分配器和
发射器；它不是独立正确性 oracle，也不证明实际 token 解释成功。

原始诊断命令导入也属于测试支持。诊断使用生产冻结命令物化器，第二套递归语句发射器已删除。
私有调度检查接收描述符并保留构造计数，不重新解析语句。
冗余 `CollectSyncParameterBounds` 转发函数已删除，调用者使用现有调用证据结果。

保留的适配器用于定向分配/控制测试。生产覆盖仍由实际 token 测试及独立访问、顺序、匹配和
物理复用 oracle 建立。仅有测试调用者不构成保留第二套生产算法的理由。

源代码清理通过 363 项聚焦测试及两项定向计数检查。16 个生产 C++ 输出逐字节相同，
235 条有序轨迹和九个独立语义用例通过。这保持既有协议，不构成设备结果。

后续审计删除了仅供诊断使用的完美嵌套压平模式。所有访问检查现在使用生产路径的
原始坐标帧表示；有限和简单循环的生产路径保持不变。保留独立的重置、选择器和覆盖边检查。
仅旧诊断表示可分配的深层合成嵌套现在明确验证生产证书拒绝；该拒绝不证明物理不可行。共享旋转重置用例现在报告生产原始帧导出拒绝，
不再公开仅旧诊断模式可提供的数学结果。

## 审查和验证

四个阶段均通过独立审查后再推进。聚焦测试分别通过 54、186、268、188 项；这些测试集
相互重叠，不能相加作为独立测试数量。最终两项绑定计划冒烟测试也通过。先前的诊断和
绑定替换失败已在相应审查关卡关闭前修复。

最终比较覆盖 16 个内核：生成 C++ 全部逐字节相同，235 条有序命令轨迹一致，九个用例通过
独立访问、顺序、匹配和复用检查，包括有限 matmul、向量、旋转、嵌套、库 GEMM 与 Qwen
投影。聚焦消融测试仍覆盖八种适用调度组合。
