# 在保守前缀父区域中保留带事件的子区域

本检查点扩展显式子区域提供者接口。即使父区域的控制流不能被数值精确导入器
接受，本地计数子区域仍可保留紧凑的精确令牌实现。默认分派不变。首个支持族
尚不能接纳包含 GM 加载的 Qwen K 区域：其外部读取和自由地址坐标仍需单独验证
的投影构造。

## 提供者和所有权

`prepare_eventful_sync_children(original, scopes)` 为整个请求构造一个原函数的
语句/定义索引。每个请求范围保留原节点、祖先框架、支配它的无信号绑定，以及
一份不可变数值分析。区域数学请求只包含必需绑定，并在每个依赖的原始使用位置
检查支配关系。数学结果归绑定所有者持有；原始上下文证明它与父区域的关系。
不采样或特化任何调用。请求范围必须唯一且互不重叠。

初始支持族仅接受本地存储效果、静态内部计数框架，以及无隐藏通知资源的合格
原生操作。不同本地描述符之间的物理别名仍然保留。自由调用者/外层坐标（包括
类型元数据中的坐标）和外部效果被拒绝。保守父区域不从子区域继承 GM 不相交
前提。缺失的精确选择器保持不可用，不为组合伪造答案。批请求原子地返回所有
句柄，或在不修改 IR 的情况下拒绝。

共享索引只遍历原语句树一次。每个查询仅访问所需范围、祖先和必需绑定；静态
绑定资格只在本请求中缓存。`describe()` 读取保留的成本，不运行识别或构造
导出。共享索引大小按批计一次，不能对每个子区域重复求和。这消除了重复扫描
整个所有者的开销，但不意味着导出是常数成本或整个编译器具有线性复杂度。

## 组合与正确性

父区域通过现有保守效果类按流水线和读写模式保留所有可能仍待完成的子区域
效果。通知闭合不会删除负载效果。现有无 KILL 传递、服务剪枝和分配算法不变。

入口为每一对有序参与流水线加入闭合服务：

```text
record(p); wait(q); record(q); wait(p)
```

所有入口服务都受原子区域调用的同一守卫控制，并在每条参与流水线上先于调用。
其逻辑效果在物理分配之前显式存在。任意子区域命令不参与父服务剪枝。

对于方向 `p -> q` 的子区域标志，上一次在 `q` 上的消费先于入口发布 `q -> p`；
该发布在 `p` 上的获取先于下一次子区域发布。因此，跨访问、计数器重置、跳过
执行，以及不同合格子区域之间的转换，均具有消费先于重发布的因果路径。共同
私有调色板的安全性来自这个包装证明；只取子区域预算的最大值并不充分。

父角色通过现有方向资格和原生预留接口分配。子区域只得到排除所有父角色 ID
后的共同合格调色板。保守求交可能拒绝实际存在方向性分配的情况；这不是新
着色算法，也不是容量下界。缺失方向、资源不足、匹配/框架证据缺失保持独立。

`LowerSync` 重新解释实际令牌程序，包括序列化输入。版本化子区域标记仅用于
路由，不提供证明。降低过程重新建立词法绑定，并对负载流水线、record 源和
wait 目标求并集，避免纯命令服务隐藏资源参与。它验证入口确认，并通过现有范围
令牌解析器、匹配解码器和分配器降低去掉标记的子区域。原命令位置和内部顺序
保留。嵌入后，每个 SET 自然包含其源流水线上的先前父等待，与逻辑 record
一致。因此，子区域内部证明在先前前缀扩展下仍有效。闭合匹配既不证明子区域
出口负载完成，也不证明调用完成；最终边界机制仍单独处理。

新的完成 SSA 名称由父命名所有者统一提供。负载变量、原归纳变量、存储描述符、
守卫和坐标身份保留。失败的准备或降低不发布部分物理程序或资源声明。

## 复现和证据

聚焦测试位于 `tests/ut/ir/transforms/test_eventful_sync_children.py`。测试含有
子区域前后的父访问、共享本地字节、零/一/多次访问、条件跳过和内部计数器重置。
另测原所有者移植拒绝、外层坐标不可用、完整入口服务缺失、合格资源不足、实际
令牌序列化、共同调色板与命名，以及 K 和静态子区域数量变化时的保留大小。

可复用资格验证入口为：

```bash
PYTHONPATH=python:tests/ut/ir python -m transforms.qualify_eventful_sync_children \
  --output build-py314/eventful-child-20261115/qualification-accepted
```

它比较同一保守前缀策略下的原始逐操作实现与保留子区域实现。独立解释器重建
物理字节和实际逻辑/物理命令图。具体参考把访问冲突加入原生事件图，并采用既有
独立验证的 Cube 累加器豁免。检查覆盖、匹配、无环性和因果复用，然后分别报告
两个方向的完整完成到开始关系差异、额外前提，以及静态/执行命令数。计数下降
本身不证明关系包含或加速。单次阶段时间仅供描述，不能累加包含关系的计时。
较大的 K 只检查保留状态；有界预言机可以展开小测试实例。

最终集成门禁通过 183 个测试，包含全部 16 个子区域聚焦测试；全部配置钩子
（包括完整 pyright）通过。在 18 个有界执行上，同策略比较没有新增完成到开始对。K=3、访问三次时移除
九个对，额外前提从 32 降至 23，SET/WAIT 执行数各从 180 降至 111，屏障从
46 降至 25。这是有限执行上的关系包含证据，不是统一支配定理。K=0、入口被
访问三次时，负载顺序相同，但入口开销使 SET/WAIT 各从 72 增至 96，屏障从
19 增至 25。

K=2/17/1023/1,000,000 时，保留计数均为九个已分析发生、五个单元、一个区域、
六个范围节点和五个绑定。这些是生产请求计数，不是预言机展开。静态子区域数为
1/2/4/8 时，共享源索引节点为 24/30/42/66，查询范围节点总和为 6/12/24/48。
经固定 PTOAS 路径的源生成也成功。机器可读凭据记录工具/源和产物哈希。
这些主机模型检查不意味着设备执行或原生缓存可见性已获得资格。

## 对论文的影响

| 已建立构造 | 剩余前提或限制 | 合适的表述 |
| ---------- | -------------- | ---------- |
| 在不规则保守父区域中保留原上下文的本地数值子区域 | 仅覆盖所述本地/静态提供者族 | 精确内部需求可与保守父服务共存。 |
| 显式入口确认及父/私有调色板隔离 | 方向、原生资源、匹配和分配资格均须成功 | 闭合通知可跨访问统一重置，而不假设子区域出口负载完成。 |
| 实际令牌重建和独立已发射命令检查 | 有界检查不能替代统一包装证明或原生资格 | 在已接纳主机模型内，降低保留所提供的父区域选定顺序。 |
| 共享原所有者索引和不随行程数增长的保留大小 | 导出/接口工作及后续编译需分别计费 | 演示族保留数值紧凑性，不主张通用组合界。 |
| 首个族仍拒绝外部读取 | 仍需按角色区分的就绪证明及显式不完整 GM 导出覆盖 | 本检查点不建立整个 Qwen 的精确性或通用外部存储子区域导入。 |
