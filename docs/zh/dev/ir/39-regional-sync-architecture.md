状态：五个实现关卡均已在下述范围内验收。原始聚焦测试 525 通过、1 个原有
分析前准入失败；下述架构后续关卡最终为 651 通过、同一个原有准入失败。英文版本是规范来源。

## 目标与 RFC

遵循 [RFC #3375](https://github.com/hw-native-sys/pypto/issues/3375)，保留放置后的
Buffer IR 和不可消耗的完成 token。InsertSync 生成依赖；OptimizeSync 保持
逻辑语义；LowerSync 解释实际 token 使用，经资源证明和现有分配器生成命令。
2026-11-14 检查时 RFC 仍开放，最后更新于 2026-11-10，无评论。

AIR 提供结构化异步依赖和分离降低的参考；PTOAS Frontier 提供区域顺序与复用
证明的参考。不整体复制其调度器或依赖提取器。PyPTO token 表示源流水线前缀
完成，不是仅表示单个操作完成。不新增公开方言、后端，不改变分块、载荷调度、
ID 池、准入上限，也不展开整个循环嵌套。

```text
Placed Buffer IR + operation/native contracts
  -> InsertSync -> logical completion-token IR -> OptimizeSync
  -> LowerSync: actual-token interpretation
  -> retained unassigned protocol -> certified palettes
  -> existing allocation -> immutable AssignedSyncPlan
  -> command descriptors and emission
```

## 所有权和能力

输入所有者保留原函数、完整操作清单、物理存储身份与别名、访问精度、原始
坐标框架、槽选择、就绪事实和显式调用者约束。精确足迹、保守包络和未知效果
必须区分。数学结果保留有限、旋转或数值表示；需求、查询、选择器和可执行端点
是独立能力。选择器区分精确答案、覆盖域内已证明不存在和不可用。导出失败不
丢弃数学结果或其他域的有效导出。子区域边界不完成载荷，也不重置资源。

数学分析和实际 token 解释共用数值合并与查询算法，但分别保留边来源和证明
所有者。前者提供存储需求，后者仅提供实际 token 依赖和原生顺序。共享阶段
摘要不能替代原始 occurrence 身份。保留四种开始/完成查询。现有较强的
完成到开始顺序可作为复用充分条件；证明失败不表示命令可达关系不存在。

一个不可变协议骨架保留每次可消耗交接、匹配身份、发布/消费切点、同切点命令
顺序、含空洞的精确活动域、坐标映射、方向、调用域及入口/出口通知义务。多个
token 使用仍是多个交接，除非另有协议证明。归一化保留使用的多重集合。
排名、复用证明和发射必须消费同一骨架。

AssignedSyncPlan 绑定精确协议、原始所有者/框架、调用域、目标和资源声明快照。
缓存归属于不可变所有者；修改 token、框架、守卫、调用约束、协议顺序或资源
声明会使相关证据失效。坐标适配必须变换或失效导出。消费者特化不能只按 token
身份缓存。

## 经过证明的调色板

当前 scoped 路径通常为一个 family 的整个跨度保留一个 ID。扩展允许多个逻辑
记录引用同一个经过证明的调色板，同时保持命令、匹配身份和活动域。

初始类别是确定的有限数值阶段计划：已证明的前缀、周期、尾部、嵌套坐标和
重置，以及活动/算术界和已支持的 capture/carry。任意动态历史和通用 fanout
实现是后续工作。

对每个方向资源命名空间和执行域，从协议计划构造发布流；以包含前缀、周期、
外层访问和同切点顺序的排名 n 编号。重置后的局部 IV 不足以标识发布。依次
考虑 B=1 到现有可用容量，提出 lane=n mod B，并对每个有效后继证明：

```text
WAIT(n) -> SET(n+B)
```

两个端点通过已检查的匹配映射计算同一发布排名。用经过证明的有限阶段类验证
前缀、周期、尾部、进位和重置，不把有限样本当作统一证明。无后继意味着无复用
义务，不能凭空制造 WAIT。缺失历史、溢出或框架不一致必须拒绝。

证书包含 lane 数、记录映射、带守卫的首发布/末消费边界、内部复用和调用前提。
这是充分证书，不是最小预算定理。现有分配器选择物理 ID，保持其着色算法及
chain/suffix 前提。通过现有描述符发射，不为适配容量添加同步。

编译上下文拥有目标资格、原生/显式声明和事务；生命周期仍属于实际资源域，
不能让无关调用仅因同一次编译而冲突。失败回滚 IR 和临时资源声明。

## 失败与调用边界

分别报告未知效果、缺失别名/范围/就绪前提、数学构造不可用、导出不可用、
token 实现不可用、复用未证明、已证明固定计划容量不足和调用边界未确认。
编译器生成的错误 IR 是内部错误，不能转交其他同步方案。

可执行资格需要显式检查的目标/运行时边界保证或已建立的边界协议；否则保持
不可用或整体委托。设备样本成功和通知闭合不证明返回时载荷完成。本任务不新增
drain 策略；实验回执单独限定，不能为解决容量而改变完成事实。

## 实现关卡

每关须经编译器/正确性及架构审阅接受后进入下一关。保留已有未提交修改。
迁移生产调用者并删除被替代路径，不永久保留重复流水线。

1. **基线与契约：** 固定 HEAD、脏源码、工具、输入和失败；确认框架/覆盖/
   原生所有权及独立顺序客户端。现有行为不变，降低不重新分析需求。
2. **实际 token 协议：** 统一交接、匹配、原始切点和精确域，保留零次循环和
   carry 语义；独立展开与实际使用一致，编辑 token 使旧证据失效。
3. **调色板与资源：** 紧凑排名、有界候选、统一证明、现有分配适配和事务。
   通用阶段/重置例子通过；负例精确拒绝。
4. **发射与清理：** 消费已分配映射，保留守卫共享/计划检查，删除已替代的
   period-one 限制。实际 ID 与映射一致，除 ID 重命名外有序命令不变。
5. **完整内核：** 固定原始无 swizzle Shenggan 输入，仅移除手动同步；回归
   matmul、Qwen、旋转/重置。独立变化 K、访问次数、槽、阶段、启动分区，
   分开报告分析、逻辑、资源、C++ 和调用资格。精确剩余义务是合法结果，
   内核专用绕过不是。

### 关卡 3 构造补充

从实际原切点和精确等差活动域构造仅描述发布的序列/重复语法。按原循环域端点
分区，以已证明的有限剩余类周期保留重复计数和尾部；不借用数学需求边。
显式计量计数、阶段分区和排名片段。

对候选 B，每个节点保留发布总数及至多 B 个首/尾发布。内部证明递归；序列
跨界仅有至多 B 个距离 B 的发布对。重复体每次有 P 个发布时，排名 r 的后继
体内排名为 `(r+B)%P`，访问偏移为 `floor((r+B)/P)`，起始访问域为
`0 <= q < count-shift`。P>B 仅需边界，P<=B 时已保留全部 P 项；P=0 不发布。
因此 B>P 和重置边界均不展开 trip count。

这些发布对是查询义务，不加入证明图。初版每个有向执行资源域只有一个调色板，
不声称通用调色板间着色。末消费边界由已证明的消费/发布链确定，不能仅按发布
排名推断。两端从同一匹配源坐标计算 lane，并先约简模 B 系数以避免无必要的
宽 INDEX 值；证明计数仍须检查宽整数溢出。

资源所有权审阅确认：对已支持的互斥 leaf case，现有栈作用域 Allocator 与
完整函数 RealizeSync 事务已经拥有目录、原生声明、方向资格及原子替换。
保留这些服务，不新增上下文包装层。调色板生产者从资源所有者接收候选 B，
不自行选择第二个 ID 池。这是限定范围内的所有权实现，不代表已实现 RFC 的
通用跨核/跨 pass 资源管理器。

## 论文与 RFC 的结论范围

| 已建立的构造 | 前提与限制 | 可支持的结论 |
| ------------ | ---------- | ------------ |
| 区域最小需求生成 token IR | 仅对已准入的建模访问精确 | 保留分析接口，不增加访问类别 |
| LowerSync 保留实际 token uses 和原始 cuts | fanout 各 use 独立，修改后的 token 不被需求重建替换 | 逻辑同步是真正的 lowering 输入 |
| publication-rank palette | 每个跨 phase/reset 复用都需要统一因果证明 | 支持的重复协议可跨逻辑 family 复用 ID |
| 现有分配器处理完整方向 palette | 合格且不同的 ID、原有 claims、完整事务 | 不改需求、不加同步而扩大资源可认证范围 |
| 原始 cut 发射与独立小实例检查 | 比较建模 payload 的完整前置关系 | 不据此宣称设备加速或原生返回正确性 |
| 固定周期的紧凑表示 | residue 展开和整数容量限制显式保留 | 不随 trip count 展开不等于任意周期都有常数界 |

仍有独立限制：小 GEMM 的 Buffer 准入失败发生在需求分析前；折叠 startup/continuation
frame 可能缺少可执行导出；资源“未证明”不等于容量不够；动态历史、跨核资源所有权、
原生 footprint 和调用边界需要另外的契约。不能靠改变 tile 或复制手工同步掩盖这些限制。

## 有界架构后续关卡（2026-11-14）

基线 `12e99a75c` 已在公共所有权接管前插入 A2/A3 终止 ALL-pipe 排空；
不支持的退出形式拒绝。内部子区域仍可返回未完成载荷。之前设备结果的边界
条件不同，不能直接视为当前版本性能。

三个关卡必须逐一通过独立架构和正确性评审：

1. **不可变发布结果**：将内部可变构造与只读数学所有者分离，发布时移动数据，
   不复制大清单。查询计数独立于证明状态；冻结前不能发布缓存导出。迁移有限、
   旋转、数值构造和消费者，删除公开可变访问。验证重复导出、所有者生命周期、
   不同输入隔离、需求、查询和选择器。
2. **原生实现契约**：使用现有后端配方和资源目录统一已支持变体的选择、资源
   声明和目标前提，删除分配器内部重复宏选择。访问几何仍由导入器证明。
   保持标量原生顺序、Cube 累加器豁免和调用结束排空；未知变体不能视为无资源。
3. **共享消费者契约**：在前两步后合并真实生产重复的原始坐标、端点、活动域和
   能力拒绝逻辑。缺失绑定不能默认为零，覆盖域内不存在与不可用必须区分。
   保留必需顺序和实际 token 顺序的独立所有者及专门数学算法。

每步均实现、串行构建、独立聚焦回归、审查删除与复杂度，然后评审验收。
