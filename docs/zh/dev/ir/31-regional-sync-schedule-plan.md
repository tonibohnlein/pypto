# 区域同步调度实现计划

架构修正及逐阶段验收记录见[修正记录](32-sync-schedule-architecture-correction.md)。阶段 1–4
已在记录范围内获独立接受。本页后续旧验证数据对应固定的
早期实现，不能解释为修正后默认策略的结果。

固定候选目录独立组合边界分割 B、周期展开 P 和 case 版本化 C。原循环及 C 保留原始
上下界；B 仅提供区间事实；P 仅提供可选同余事实，在没有 B 时保留端点守卫，并负责
自身必需的余项。周期证明不成立只排除 P，不排除原循环或 B。所有模式保持同一边界
命令移动策略，并对每个完整候选重新证明。物化器仅消费已选择的描述，不决定变换。

生产默认不增加载荷操作站点。显式诊断策略每个函数最多允许增加 4096 个载荷站点和
65536 个展开 IR 节点。这是有限编译器策略上限，不是设备性能结论。IR 上界包括操作数
出现次数、复制的标量定义、控制及命令；描述 DAG 共享不会减少该计数。载荷增长按源程序
循环顺序扣除预算。控制节点使用零作为 guarded 基线下界，扣除完整替换上界；该规则
比扣除实际额外增长更严格，即使源程序序列包装被展平也保持安全。强制模式只绕过模型收益判断，仍检查合法性和预算，并分别报告请求
不适用／超预算及 guarded 回退，不能把回退计为成功消融。

自动选择始终与同一 guarded 基线比较完整候选。模型分别记录算术、比较、布尔运算、
分支、循环头和生成的 SSA 绑定。case 成本使用区间差分累加，谓词成本复用发射器的
作用域内共享资格规则；不支持的混合谓词使收益未获证明。自动选择须在至少一个 case
改善且其他 case 不增加；成本相等时优先较小代码及较少变换。`model_exact` 仅描述该
生成控制模型，不表示设备周期或全部载荷成本；独立执行控制计数另行验收。

C 通常复制循环体。纯谓词共享保留一个载荷主体，必须单独测量，不能称为无复制 case
版本化。诊断区分候选／证明检查工作、已选描述及实际输出计数。实际 token 域、已有
ID 映射及分配权威保持不变。

起点为 `868fdd471` 加已审查的边界调度改动。
`build-py314/regional-schedule/baseline/pins.json` 固定工作树内容和扩展版本。
实际 SSA token 决定通信，已有分配器决定经认证的 ID 映射；调度不改变需求、协议、
硬件豁免、资源池或物理存储。

内部使用一个调度所有者，在选择结构化实现前保留原始切点、族身份、活动域和 ID 表。
case、阶段和余数保持分解，不计算全局 LCM，不隐式枚举笛卡尔积。
合格循环可构造前序、稳定段、余项和尾段；给定共同周期 P 的稳定段使用 P 个按原始
坐标特化的载荷体。阶段边界不隐含完成或旗标重置。未知前提保留原有 guarded 调度。

代码大小在合格类中不依赖迭代数，但必须显式计入载荷复制、命令、控制和证明成本。
编译器 DAG 共享不等于输出代码共享。立即数 ID 可能要求一个族对应多个静态命令位置。
调用分支只能移动到合法且值就绪的作用域。ID 重命名必须是覆盖完整封闭资源作用域的
方向性单射置换，保留资源资格、预留和所有者；不兼容的颜色共享模式不能强行合并。

按以下阶段实施，后一阶段必须等待审查接受：

1. 共享所有者：先收集符号命令再降低，保持原输出、所有权和拒绝行为。
2. 规则调度：支持 Qwen 周期一边界和真实周期 ID 用例；稳定段无新增边界/ID 选择器，
   保留完整轨迹并计数所有复制。
3. 调用集成：共享经证明的公共调度，不兼容 case 保留；重命名需完整资源证明。
4. 合并：删除旧逐族展开及独立边界/case 所有权，保留单一调度编译器中的实用规则。
5. 验证：独立检查实际顺序、匹配、物理复用，并分别变化迭代、静态阶段和 case 数。

主要实现位于 `physical_sync_realization.cpp`；`structured_token_sync.cpp` 保持 token
解析权威性；分配接口不改变着色算法；头文件和测试绑定记录构造/复制计数。
保留已有边界测试，并加入阶段、余数和 case 结构与语义验证。

## 已实现的所有权与正确性约束

`AssignedRegionSchedule` 在生成标量控制之前收集全部调用情况，引用实际
令牌的端点域和已认证的物理 ID 映射。函数与不可变端点域由该对象持有；
输入和分配结果在同步编译调用期间借用，不复制数学结果。

`PlanRegularSchedules` 仅接受常量正步长 INDEX 循环，不允许循环携带结果、
分配、任意标量定义或嵌套控制。允许槽视图定义和已认证的初始化/累加共享
插入点。必须覆盖被替换循环体中所有情况的全部命令与端点；使用加宽算术
验证坐标、归一化范围、分组步长和最后一次递增不会溢出。

周期为一时按端点边界分段。公共物理 ID 周期 P 大于一时，只展开最长的
均匀区间；前缀、余数和尾部保留守卫。不构造周期最小公倍数，也不扩展
尚未支持的嵌套非单位 ID 映射。ID 选择使用原始序号减去端点起始序号，
不能在阶段边界重置映射。

每个输出循环体只克隆一次，SSA 定义为新对象，捕获的存储分配保持不变。
逐次访问的载荷与命令顺序完全保持，因此在相同原生模型下保持匹配、因果
复用和载荷顺序。阶段边界本身不提供完成保证。

`PreparedSchedulePhase` 在标量语句生成前保留命令描述。调用规则按完整有序
描述的精确比较分组；哈希只用于索引。分组域保留区间并集及其空洞，没有
命令的情况仍执行载荷。在支配循环的原始启动坐标上分派完整循环计划；
不重命名 ID，不改写代表情况的输入界限或分配证据。保留描述的全部原有守卫（包括启动谓词）与坐标；只提升新增的情况分派。

成本门槛显式计算循环控制、坐标运算和执行判断。调用分派的节省相对于
实际已合并的逐插入点计划计算，并扣除选中描述中仍存在的谓词。未知守卫
不提供保证节省。区间遍历通过范围累加避免对每种情况重扫整棵树；碎片化
并集仍支付其区间表示成本。这是主机 IR 单位工作模型，不是设备延迟模型。
载荷副本和源码字节单独报告：执行控制减少可能增加源码大小。

## 验证检查点

全部五个阶段获得独立审查接受，前四阶段均在进入下一阶段前通过审查。最终机器可读记录见
[regional-sync-schedules.json](../../../en/dev/ir/regional-sync-schedules.json)。
基线为固定的起始未提交工作树；M1 输出与该基线一致，比较使用 M1 序列化函数。

最终活动包含 28 个样例、477 次有序载荷/物理命令轨迹比较，全部一致；其中
9 次还运行独立访问与命令图检查。测试覆盖周期槽、原始坐标、跳过/空分支、
重置、同管线硬件豁免和消费先于再发布。相位复制产生新 SSA 名称，因此检查器
逐操作数比较分配、基址、形状、步幅、布局、有效类型和标量值，以及操作与属性，
随后仅从原始输入构造一次字节冲突。编译器生成器或哈希相等不能代替访问证明。
短循环与稳态可以具有不同静态站点数；分析表示大小仍受检查，矩阵测试检查执行屏障。

初次完整门禁为 **1614/1635**。21 个失败包括操作数检查器的两个浮点字面量
缺失，以及十九个相位专门化前的静态布局预期。修复后十个完整受影响文件
**373/373** 通过，含两个新的参考所有权回归；原有失败 ID 均通过重测。
这不是一次新的全套全绿运行。修复未改变协议、需求或分配算法。

审查还发现两个审计报告从不含访问集合的新调用重建参考。执行检查本身始终
使用原始效果。报告现保留原始调用和原生作用域身份，刷新结果替代旧的顺序行。
完整会计审计检查 28 个样例；重建审计成本与生产时间分开记录。

最终仅样式调整的 C++ 重建还通过 **104 项定向测试**。56 个生成 C++ 输出、
28 个表示/审计结果及 477 次轨迹测量与此前语义构建一致。审查者核对当前源码和
修正记录后接受 M5；设备/缓存性能、原生返回行为和不支持的调度类不在接受范围内。

### 复现与范围

完整命令见英文同名页面；使用 Linux 测试环境、固定 PTOAS wheel 和 PATH 上的
Python 3.11，构建显式使用 `--parallel 1`。机器记录包含源代码、扩展、输入及日志
哈希、完整测试命令。数据位于磁盘工作区；本次没有设备验证。

| 已建立结果 | 限制 | 可支持的论文表述 |
| ---------- | ---- | ---------------- |
| 使用实际 token 域和已认证 ID 映射 | 未改变需求分析或分配 | 需求之后的可执行表示改进 |
| 合格相位/分支保留原始有序轨迹 | 继承原生管线与调用前提 | 相同模型顺序与物理协议 |
| 同周期余数专门化及区间分割 | 字面正步长 INDEX 循环；不支持一般混合周期和作用域非单位周期 | 指定子类控制大小独立于访问次数 |
| 精确区间并集分派 | 不重命名 ID，不合适坐标仍阻止共享 | 身份与可用性一致时共享完整调度 |
| 477 次检查中控制工作降低或不变 | 代码增大，无目标延迟/缓存模型 | 主机控制工作减少，不是设备加速 |
| 保留独立覆盖/顺序/复用检查 | 非任意 token 或原生进入/返回证明 | 有范围的模型级验证 |

实际输出仍含 G 个调度组乘以有限相位/余数主体的乘积：单位周期为
O(G·B·(payload+commands))，支持的非单位周期规则为
O(G·(P+3)·(payload+commands))。共享描述不会消除这一已计费输出乘积；
避免的是无界联合周期状态枚举。报告使用显式保留的原始调用及参考关系，
不从新 SSA 调用重新推断原生硬件作用域。
