# 运行时有效行广播：使用点元数据证据

状态：独立审查者已接受设计与源码；最终集成构建、测试及提交结果记录在英文配套 JSON
回执中。本工作扩展通用自动同步架构计划的 M2（共享操作与元数据资格），并供 M3 消费，提供可复用的操作与元数据服务，
不按 Qwen 内核名称放宽准入。

FP32 `col_expand_mul` 支持静态物理矩阵 `[M,N]`、运行时有效行 `r`、固定且完整的
正列数 `N`、完整有效的 `[1,N]` 行向量以及同形目标。既有物理布局、别名、放置及
本地重复/步长限制保持不变。新运行时变体仅对 A2/A3 完成源码资格审计；A5 仍拒绝。

`BufferRuntimeValidAnalysis` 读取实际分配与 `buffer.set_validshape` 参数，在使用点
证明源与目标有效行相等、矩阵完整列数、行向量状态和正行条件。描述符中的 `-1`
不构成相等证明。数值证明仅使用实际有符号整数 SSA 值、常量及其原始比较条件，
不通过未证明溢出安全的算术代换推导关系。不支持的分支条件在两臂均不提供事实，
不能将它替换为真后再把假条件用于 else 分支。

此服务由 Buffer 验证及代码生成消费；可执行所有权还通过共享调用资格服务消费它。
标量内存就绪与可见性仍为独立义务。降低在每次数据使用前恢复原始有效元数据，
设置输出状态并以 `r > 0` 保护广播。零行广播只更新自身元数据，不发出该原生操作；
例如行向量加载等其他操作保留原始控制。

分支合并和循环边界通过代数失效索引状态，无需扫描所有句柄。未知状态保持不可用，
直到新的所有者设置器建立证据。当前仅支持普通分配拥有的元数据，不推断槽、借用
句柄或任意别名之间的元数据共享。`0 <= r <= M` 是既有 Buffer 操作的输入有效性
前提，并非新建立的调用者上界证明；访问包围不能修复无效元数据。

固定原生实现 `pto-isa 5487a6b0` 的 CountMode 使用完整 `N` 的计数掩码逐行执行
显式输入/输出 VMUL，然后恢复向量掩码。此变体无隐藏暂存及编号事件操作。
源/目标使用点行关系与正行保护建立其元数据兼容性，不证明子区域返回时所有载荷
已完成，也不构成精确动态存储选择器。

独立主机测试覆盖行数 0/1/7/8、选择与跳过分支、内外多次调用及计数器重置。
Torch 重放检查有效输出值与无效行哨兵；独立解释器读取真实元数据、展开物理字节，
分别检查保守效果覆盖、实际冲突、逻辑 token 与物理程序的完整载荷事件序相等。
未使用的不可变完成事实可在降低时消失，不能按消费型标志比较其命令身份。
实际 SET/WAIT 匹配、无环性、六 ID 资格及消费先于再次发布分别验证。

拒绝测试覆盖无关动态行、缺少正行保护、两臂未资格算术条件、合并/回边失去元数据
以及不支持的目标。行程 3/1000000/2000000 的静态站点与状态计数保持一致；此证据
只说明这些行程不被展开，算术表达式证明成本另计。无设备验证。

原始 Qwen post-RMSNorm 还需要动态归约与连续 `[M,1]`/`[1,M]` 有效轴导出。
其 IR 将部分有效归约结果与完整有效累加器相加后返回完整有效结果。本工作不证明
归约无效尾部初始化为零，也不假设调用者 `r=M`。混合有效域相加仍是独立操作契约义务。
