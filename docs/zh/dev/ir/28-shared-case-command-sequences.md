# 共享情况决策与命令序列

本阶段实现[同步代码展开核算](27-sync-expansion-accounting.md)的首个目标：减少情况
选择重复，保留选定协议及物理 ID。基线为
`4f5fdfeada1085841de6cb5bfd7637d391a9663e` 加未提交的核算诊断。
[回执](../../../en/dev/ir/shared-case-command-sequences.json) 固定起始和最终源码、工具及输入。

## 位置与契约

变化位于 `physical_sync_realization.cpp` 的现有 `EmitSyncCommandCases` 中，供生产
令牌降低及诊断物理实现共用。它处理单个原始载荷前/后插入位置上已分配的命令序列，
不重跑需求分析或分配，不改变逻辑令牌语义，也不引入新同步 pass。

输入沿用发射器专用契约：物理命令叶子、序列及依赖就绪不可变原始坐标的守卫，
不包含载荷或定义。插入位置的可能执行域是保守上界；缺少不存在证明时使用完整域。
会执行但没有命令的情况，与已证明不执行的情况不同。

现有完整序列合并先执行，然后新构造：

1. 仅展平无条件序列容器，将带守卫命令保留为具有原始 SSA 身份的不透明树。
2. 构造有序情况切片，对未覆盖但可能执行的区间加入空切片。只省略无法到达原始
   插入位置的区间。
3. 建立平衡二叉决策树。所有后代共有的前缀在决策前执行，共有后缀在决策后执行，
   保留内部顺序和重复命令。子树继续处理剩余切片。
4. 与原发射结果比较。只有命令站点、条件站点和表达式出现次数均不增加，且至少
   一项减少时才接受，否则保留原结果。

例如 `[A,B,D]` 与 `[A,C,D]` 变为 `A; if case: B else: C; D`。
`[A,B]` 与 `[B,A]` 仍是两个有序选项。相同标签不允许交换命令、合并发布或重命名 ID。

## 有效性论证

对每个到达该位置的允许执行，恰有一个区间切片适用。二叉比较选择其子树。每个节点
提取的前缀和后缀在全部后代切片中结构相同，从各切片删除一份并执行共享副本，保留
选中序列的顺序。归纳终止于原始叶子的剩余序列。

显式空执行切片阻止将命令提取到原先没有命令的路径。仅在所提供可能域之外才能跳过
缺失区间。原始前/后位置保持分离，命令不跨越载荷或原始控制边界。内部条件不脱离
自身守卫树，被跳过的坐标表达式仍被跳过。结构比较保留自由变量身份；不支持的比较
只失去共享机会，不使原计划失效。

因此每次执行的命令、方向、ID、重数和相对载荷位置均保持。已有匹配及因果复用证明
仍作用于同一协议。这不建立缺失的原生调用返回前提，也不允许任意有副作用控制作为输入。

## 工作量与限制

令 C 为区间切片数，S 为输入顶层命令序列项数，T 为展开后的语句/表达式大小。
平衡递归深度为 O(log(C+1))；每层最多检查 O(S+C) 个序列项，不透明树的结构比较
单独计费，保守上界为 O(T log(C+1))。区间相交使用规范化可能域的索引查询。
不枚举动态循环实例或启动索引。构造保留 O(S+C) 的序列/树存储，并借用原始表达式树。

计数器包含被拒绝的候选尝试：`case_sequence_visits`、`case_sequence_comparisons`
和 `factored_case_cuts`。大小核算的表达式遍历计入 `control_expression_visits`；
结构比较库内部工作仍单独说明。静态 Pareto 接受条件是代码指标，不证明每条路径运行
成本更低，也不是设备计时模型。

本构造共享决策树节点上的前缀和后缀，不求最长公共子序列，不统一各情况 ID 分配，
不跨载荷位置共享，也不拆分循环阶段。`OptimizeSync` 继续验证逻辑令牌；本变化优化
其现有物理降低路径。

## 结果

28 个用例输入的哈希均与基线一致。比较 477 条有序载荷/命令跟踪，覆盖每个 Qwen 用例
的两层及全部 block，ID 和命令重数全部相同。生产和诊断路径使用同一实现。

完整同步测试通过 **1,562 项**（37 个警告），最终聚焦测试通过 **39 项**（五个警告）。
完整测试收集后收紧了生产代码大小上界，最终聚焦运行验证这些最终断言。Ruff、聚焦
类型检查、clang-format21、cpplint、Markdown 及中英文文档一致性/导航检查均通过。

大小。合成测试使用 8/32/128 个情况，每个区间宽一百万；共享前后缀后有 C+2 个命令
叶子和 C−1 个决策，不枚举启动域。

28 个用例的前后版本均生成并检查 C++。控制活动中的独立访问/顺序检查及 C++ 顺序
活动区分了前置关系不变与静态代码减少。论文的多余前置关系指标保持不变，没有用
额外载荷顺序换取更小代码。原生足迹、标量命令发出及入口/返回假设仍需分别限定。
本次没有设备实验。

单次编译时间是描述性数据。诊断重建和语义检查器不计入生产时间。band 2 诊断处理
1,444 次情况序列/大小访问和 114 次不透明序列比较，接受 30 个位置。没有引入新的
数学分析或物理分配。

## 复现

使用现有 Linux 构建、Python 3.14 扩展及固定 PTOAS v0.72。PTOAS 启动器需要 PATH
包含已限定的 Python 3.11。其他机器工作可能占用第二个 worker 时，使用串行构建。

```bash
source .claude/skills/testing/load-env.sh
export PYTHONPATH="$PWD/python:$PWD"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYPTO_CODEGEN_MAX_WORKERS=1
export PTOAS_ROOT="$PWD/build-py314/physical-sync-prototype/ptoas-v072"
PYPTO_TOKEN_PY311=$(dirname "$(readlink -f /home/toni/.local/bin/python3.11)")
export PATH="$PYPTO_TOKEN_PY311:$PATH"
cmake --build build-py314 --parallel 1
/usr/bin/python3 -m tests.ut.ir.transforms.qualify_sync_control \
  --baseline build-py314/cut-control/final \
  --output build-py314/case-sharing/final --emit-cpp
/usr/bin/python3 -m tests.ut.ir.transforms.qualify_sync_order \
  --physical build-py314/case-sharing/final \
  --output build-py314/case-sharing/ordering
```

回执记录精确回归命令和结果。通用测试覆盖空/缺失情况、域空洞、原始 SSA 身份、
被跳过且不可用的值、重复命令、相反命令顺序和重复访问。确定性生成测试增加 100 个
序列/域组合。基线序列化 IR 和源码哈希保留在磁盘活动目录中。
