## 坐标合同

`RealizeSync` 现在是程序级 Pass，在尝试每个内核之前检查原始直接调用方。
`CollectSyncParameterBounds` 复用 PyPTO 的 `ConstIntBoundAnalyzer` 环境和已有
Call/Submit 实参映射，合并所有直接调用点的闭区间。任一未知调用点使对应形参
的证据失效。使用标准 IR 访问器遍历 Submit 参数、依赖、启动操作数及引用属性；
运行时分配的输出不会改变标量形参身份。函数句柄是 Op，而不是标量表达式。
不运行调用图不动点，也不从参数名推断范围。

支持 INDEX 常量、有界循环索引、纯标量赋值、加法和乘法，要求每个中间结果
非负且不溢出。访问导入还要求仿射形式。先证明范围再规范化；溢出的表达式不会
因为随后乘零而合法。未知值、窄类型转换、减法、符号循环上界和跨过程参数转发
保持未证明状态。不能用一次分支采样建立范围。

形参在调用入口已就绪，在调用期间保持不变。本扩展不引入标量负载指令或跨管线
标量就绪证明。生产证据属于当前编译的封闭程序。严格研究 API 的
`parameter_bounds` 以**原始形参位置**索引，是显式证明前提，不是运行时样本。
孤立函数缺少证据时仍拒绝。

## 平移保持精确需求的理由

对每个 GM 域 `s`，所有访问必须具有相同参数平移 `T_s(p)`，其余部分是已支持
的相对足迹。因此物理足迹为 `T_s(p) + F_i`。固定调用内，平移为单射，保持
该域所有读写的交集。不同 GM 域仅在现有显式 `autosync_disjoint_gm` 调用合同下
互不重叠。本地放置和硬件资格不变。检查上界保证平移足迹及中间算术不越过
静态分配边界。

现有归约器因此为所有允许参数值计算同一建模闭包和覆盖边。数值秩及距离结果
只保留一次。发射程序使用原始地址表达式，不针对某个任选偏移重新分析。

存储导出保留平移系数。`boundary(..., parameters)` 验证绑定范围并把查询点
转换到相对坐标。缺失/无效绑定返回不可用 (`None`)；已覆盖但未访问的点返回
可用且读写者缺席的答案。本地域不要求 GM 参数绑定。事件查询不必按参数特化，
因为共同平移不改变选定顺序。

该论证不证明不同调用之间不相交、通知资源重新就绪或原生返回完成性。
原有新鲜入口、通知闭合及运行时调用前提继续适用。

独立解释器从原始 IR 与参数绑定计算实际访问，不依赖编译器单元或生成器。
检查足迹一致性、独立冲突闭包、实际保留覆盖边、四类事件查询和边界选择器。
命令检查器验证匹配、无环性、方向容量、消费先于再发布的因果关系，以及已检查
执行的建模负载顺序相等。原生宏及访问语义仍是输入前提，而非芯片验证结果。

原始两个内核各检查三个偏移组合；K=1、2、3、4 的正长度配置衍生覆盖短程与
稳态行为。K=0 会使本 GEMM 源码的最终 store 读取未初始化累加器，不能宣称是
合法衍生。已有零体和重置测试保持独立，不凭空增加初始化。

K=4、8、64、1,000,000 时，保持 16 个分析出现、11 个单元、五站点重复体、
六个重复需求族、100 个距离条目和 7/7 个静态 SET/WAIT。K 以数值保留。
这是现有单层重复类的紧凑性证据，**不是**嵌套 Qwen 组合验证。计时为单次描述性
测量；分析细分包含在分析总时间内，物理实现含分配和发射，不得相加重叠计时。

## 尚需实现的嵌套组合

已将固定的 Qwen `_out_proj_aic_phase` 原始主体作为独立区域降低，未编译整个模型。
首个生产边界是 Buffer 选择：`SelectBufferIRFunctions::CheckType` 要求静态 Tensor
形状，但权重的首维为 `LAYER_HIDDEN_ROWS_DYN`。本地形状及 ND 行步长已知；
仍须保留动态分配边界并证明层偏移、转换和访问范围，不能代入基准层数冒充合同。

随后还有表示边界：当前结果只有有限/单层重复区域的平坦序列；Qwen 有输出 tile、
K 流水和操作数填充三层。下一步应扩展现有 owner：

1. 保留子结果及多层原始坐标，导出原生/存储边界和全部事件查询，不枚举子访问。
2. 用端口组合 K 阶段，保留 Mat 操作数整个填充周期的驻留期，区分首次初始化、
   后续累加和下一输出 tile 的重置。
3. 利用子可达性联合归约跨边界边，向外保留输出成员关系和选择器；重置后复用
   输出需在外层重新检查，不能沿用内层不相交证书。
4. 扩展端点坐标转换，用相同混合事件查询证明物理复用；通知闭合本身不足以重新
   使用下一访问的 palette。
5. 独立检查有界嵌套实例的覆盖、查询、选择器和命令，分别测量外 K 与内填充规模，
   再应用于 gate/up。
