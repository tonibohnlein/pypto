## 坐标合同

`RealizeSync` 现在是程序级 Pass，在尝试每个内核之前检查原始直接调用方。
`CollectSyncParameterBounds` 复用 PyPTO 的 `ConstIntBoundAnalyzer` 环境和已有
Call/Submit 实参映射，合并所有直接调用点的闭区间。任一未知调用点使对应形参
的证据失效。使用标准 IR 访问器遍历 Submit 参数、依赖、启动操作数及引用属性；
运行时分配的输出不会改变标量形参身份。函数句柄是 Op，而不是标量表达式。
不运行调用图不动点，也不从参数名推断范围。

支持 INDEX 常量、有界循环索引、纯标量赋值、加法和乘法，要求每个中间结果
非负且不溢出。访问导入还要求仿射形式。先证明范围再规范化；溢出的表达式不会
因为随后乘零而合法。未知值、窄类型转换、减法、符号循环上界和跨过程参数转发
保持未证明状态。不能用一次分支采样建立范围。

形参在调用入口已就绪，在调用期间保持不变。本扩展不引入标量负载指令或跨管线
标量就绪证明。生产证据属于当前编译的封闭程序。严格研究 API 的
`parameter_bounds` 以**原始形参位置**索引，是显式证明前提，不是运行时样本。
孤立函数缺少证据时仍拒绝。

## 平移保持精确需求的理由

对每个 GM 域 `s`，所有访问必须具有相同参数平移 `T_s(p)`，其余部分是已支持
的相对足迹。因此物理足迹为 `T_s(p) + F_i`。固定调用内，平移为单射，保持
该域所有读写的交集。不同 GM 域仅在现有显式 `autosync_disjoint_gm` 调用合同下
互不重叠。本地放置和硬件资格不变。检查上界保证平移足迹及中间算术不越过
静态分配边界。

现有归约器因此为所有允许参数值计算同一建模闭包和覆盖边。数值秩及距离结果
只保留一次。发射程序使用原始地址表达式，不针对某个任选偏移重新分析。

存储导出保留平移系数。`boundary(..., parameters)` 验证绑定范围并把查询点
转换到相对坐标。缺失/无效绑定返回不可用 (`None`)；已覆盖但未访问的点返回
可用且读写者缺席的答案。本地域不要求 GM 参数绑定。事件查询不必按参数特化，
因为共同平移不改变选定顺序。

该论证不证明不同调用之间不相交、通知资源重新就绪或原生返回完成性。
原有新鲜入口、通知闭合及运行时调用前提继续适用。

### 原始位宽范围证据

调用方收集器及坐标 DAG 支持有界非负整数算术和保持值的显式转换。每个中间
结果在原始类型中检查：扩宽不能掩盖先前溢出，窄化要求整个区间可表示，后续
乘零不能跳过操作数资格检查。二元运算的操作数与结果类型必须一致，否则需要
显式转换。循环递增也必须满足原始归纳变量位宽。未知、负值、溢出或不支持的
表达式继续保持未证明，复用已有范围环境及调用参数映射。

GM 动态首维仅在原始形状变量同时为具有已证明范围的显式 INDEX 形参时准入。
这依赖既有 Tensor ABI 的形状关系，不根据名称或样本推断。保留几何使用最大
尺寸，全部访问必须位于**最小**允许尺寸内；独立区间不足以证明的关系式
`offset + size <= rows` 仍不支持。查询必须提供有效实际尺寸；分配外返回不可用，
分配内未触及点返回精确缺席。本地查询不要求无关 GM 绑定。

回归覆盖 INT32 到 INDEX、安全及有损窄化、有符号/无符号循环递增、隐藏溢出、
缺失或无效尺寸绑定，以及从真实调用点收集证据的生产选择。动态循环上界、隐式
形状符号及跨过程关系仍未证明；Qwen 的隐式权重尺寸及层偏移不会因为通用测试
通过而自动获得资格。

### 不变完美循环巢

当所有访问描述与外层计数器无关、没有条件初始化/重置、没有循环携带结果时，
常量顺序完美循环巢可以共享一个有限体。保留全部原始框架、起点、步长与次数。
规范坐标通过经过溢出检查的混合进制序号映射到重复体；该映射是保持参考顺序的
双射。因此相同效果、管线及前提下，原生及存储图和现有重复体表示相同，包含
内层计数器重置处的跨界需求。零次数没有出现，原始空控制流保持不变。

物理发射在原始作用域计算序号，保留循环及负载位置。首次/末次条件和复用余数
不会在每个内循环重新开始，继续依赖原分配证书。这不意味着子出口的负载全部
完成。逻辑 token 导出在尚不能跨所有框架传递 token 时显式拒绝；保留数学结果，
也不妨碍独立合格的物理导出。

这只是**不变完美循环巢特化，不是一般嵌套区域组合**。移动切片、外层相关访问、
累加器重置、非完美主体及不支持的同 DMA 管线屏障保持显式限制。负例验证物理
导出失败后仍保留正确分析；硬件豁免和屏障策略不变。

固定深度下，分别增加两个次数直到 `10^6 * 10^6` 次叶访问，站点、单元、需求、
距离表及静态命令数量不增长。框架及序号算术随深度增长，数值需要对数位数，
此实现限制在有符号 64 位内。小实例覆盖零、单次、多次、三层循环、非零起点、
非单位步长、父访问和重复循环巢。独立检查原始访问、实际覆盖边、四类事件查询、
选择器、匹配、无环和消费先于再发布；PTOAS v0.72 生成 C++，没有新设备验证。
