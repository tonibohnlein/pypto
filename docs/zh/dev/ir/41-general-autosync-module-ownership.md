# 显式模块同步所有权检查点

本检查点完成一个有界部署接口：显式整 Program 请求可以接管空方案、仅 barrier 和有标志的本地内核，无需伪造标志。它不代表整个 Qwen 的接管，也不代表原计划 M6 完成。

## 合同与实现

`LowerSync(require_whole_module=True)` 和 `RealizeSync(require_whole_module=True)` 原子限定所有已放置的本地 AIC/AIV 函数。未知 helper、外部域、未放置存储及已接管物理程序拒绝；普通调用保持已有逐叶行为。

即使没有逻辑同步操作，也检查实际操作、隐藏原生资源和运行时有效形状的使用点证据。相同 `-1` 描述符不能证明关系。LowerSync 实现实际 token 程序，不声称手写 token 已覆盖内存冲突；RealizeSync 保留插入阶段的独立覆盖保证。

有载荷或物理命令完成义务时保留原有末尾 ALL。只有没有原生载荷，且所有物理记录实际 SET/WAIT/barrier 计数均为零时，空程序才不需要 drain；非空诊断记录本身不产生完成义务。

后端检查实际代码生成单元的每个函数及生成 helper。仅在合格 A2/A3 目标上保持 level3 物理放置、且整个单元已限定时，保留属性 `autosync_whole_module` 才允许关闭 PTOAS 插入。混合单元拒绝，默认有标志路径仍启用 PTOAS。

owned PTO 的首行标记及配套 `.sync.json` 记录精确源 SHA256、完整域清单和限定编译参数；组 raw 导出将 manifest 放在实际源旁。感知所有权的调试重建验证源字节并恢复参数。修改的源、缺失或降级 manifest、未知目标/选项、重新规划存储均拒绝。此格式检测意外不一致，不是认证机制；独立 PTOAS CLI 不读取 manifest，不属于该合同。

## 验证

所有权测试覆盖空 Lower/Realize、仅 barrier 的实际 token 顺序、最终 store drain、默认标志程序体不变、序列化、混合 helper 拒绝、实际单元清单、逐单元编译参数、组 raw 文件及修改/缺失/降级调试 manifest。缺失运行时元数据证据、目标或放置迁移在不修改输入 IR 的前提下拒绝。

联合门禁中的所有所有权测试通过。三个独立运行时有效访问测试的计量问题修正后，运行时门禁为 14/14。最终集成门禁为 183 通过、111.50 秒；所有仓库钩子（包括完整 Pyright）通过。英文配套 JSON 固定当前脏源、集成二进制与日志。以上为主机检查，没有设备验证。

## 剩余义务

| 义务 | 处置 |
| ---- | ---- |
| 标量 GM 值和控制 | 保留原生标量顺序；没有本地写入不代表缓存可见性成立。缺少明确合同仍拒绝。 |
| 本地传输和 AIC/AIV 通信 | packed column 传输独立限定；跨核通信仍需所有者、就绪及资源边界，地址包络不能提供这些保证。 |
| 运行时后归一化 | 固定列运行时行 broadcast 是独立切片；动态 reduction、轴元数据和全/部分有效 add 各自需要原生 footprint/padding/value 合同，不假定基准 r=8。 |
| 保留子区域 | 初始本地带事件族独立认证；只读 GM 投影和更广原始帧绑定继续独立门禁。 |
| 整模型 | 所有包完成后重新统计具名叶函数，分别报告 exact、prefix、委托；空方案所有权不代表全覆盖。 |

## 论文后果

| 已建立结果 | 剩余前提/限制 | 适当主张 |
| ---------- | ------------- | -------- |
| 实际 token 降低独立于插入 | 手写 token 可遗漏冲突 | 降低保持获准的表达顺序；插入另证需求覆盖。 |
| 显式本地单元拥有出口义务和下游模式 | 受限于已有原生目标/操作合同 | 获准族的本地部署保证。 |
| 空/仅 barrier 方案无需伪标志 | 混合域拒绝，不改自动 fallback | 显式整模块所有权接口。 |
| manifest 与参数支持感知重建 | raw 独立 CLI 不读取元数据 | 文件一致性传输，不是普遍 raw PTO 所有权。 |
