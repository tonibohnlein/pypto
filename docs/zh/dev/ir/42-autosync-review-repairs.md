# 自动同步审查修复

## R1：有界发现与独立的物理输出

闭合前缀发现对共享表达式节点只访问一次，同时保留语句出现次数。
令牌使用摘要按表达式身份缓存，并在每个实际使用处计数。
仅删除已证明为空的完成事实及其纯 SSA 别名；不支持的令牌框架在修改前拒绝。

每次逻辑到物理降低成功后，检查不存在逻辑操作、SyncTokenType 值、
元组成员和函数签名。运行时 TaskId 保持独立。
无效编译器输出在发布调用所有权之前触发内部错误。

新的主机验证覆盖 28 层共享 join 回归、八种 completed 别名情况
（有载荷或仅命令、启用或禁用优化、序列化），以及既有 carry/capture 和子区域测试。
首批五模块修复测试 166 项通过。接口测试 154 项通过，并发现此前暂停且尚未资格确认的
active-domain 测试包存在六个解析失败；单独保留这些失败记录，不作为里程碑通过证据。

这些检查建立受支持主机模型的行为，不证明原生或设备正确性。
逻辑协议、可用 ID 池和分配算法保持不变。
