# 保留只读外部效应的紧凑子区域

本检查点通过现有显式子区域接口 (child-provider interface) 扩展保留计划。
实现和独立源码审查已接受；最终验证、哈希和命令见英文同名文档及 JSON 收据。
默认分派、分配算法、六 ID 池、专家协议及零次内层循环屏障保持不变。

## 契约与有效性

仅当选定原生实现的全部显式及隐式 DDR 效应为只读时，整个闭合调用才可
使用只读投影 (read-only projection)。DDR 读彼此不冲突，也不与本地空间
效应冲突，因此删除其内部几何不会改变内部必需序。所有载荷事件和本地
访问保留。任何外部写、未知效应或缺失原生契约都拒绝。

DDR 根保留在存储清单中，其边界能力明确为不可用 (unavailable)，绝不伪造
单元或把缺失回答变为空。原有本地选择器和事件查询继续有效。父区域仍以
保守包围描述保留全部原始 DDR 读；相交父写必须得到保护。这并不提供精确
物理 GM 选择器。旧的无资源子区域导出维持原先更窄的条件。

准备与实际 token 降低分别检查该策略。原始 SSA、外层坐标和不可变绑定
上下文保留，归纳变量必须支配原始初始化器使用。仅原始形式张量物理形状的
ABI 符号可作为入口就绪元数据；同名外来变量和仅有效形状符号不可使用。
该就绪事实不提供数值界、内存安全证明或标量 GM 可见性。

原有入口确认协议、受保护子命令、私有调色板和方向复用证书保持有效。
通知闭合不代表载荷完成；父摘要不得消除待定效应。失败不发布部分 IR。

## 验证与质量

小实例独立展开原始访问，检查实际保留 covers、四种事件查询、本地边界、
明确不可用 GM 回答、零次/跳过/重复/重置、匹配和物理因果复用。
通用只读家族并不保证总是减少所有前提：一个三次访问例删除 39 对并新增 6 对，
超额顺序由 74 降为 41；每种 SET/WAIT 由 252 降为 165，屏障由 64 降为 28。
新增顺序来自已选逻辑包装协议，而非分配器。

K 为 2、17、1023、1000000 时，通用子区域维持 15 个分析 occurrence、5 个
单元、1 个区域、9 个查询节点和 5 个绑定；两个外部根及一个不可用空间保留。

原始 Qwen down_proj 整个 K 调用通过准备、逻辑组合、六 ID 分配及 C++ 生成。
保留 40 个分析 occurrence、13 个单元、3 个区域、29 个查询节点和 14 个绑定。
显式 ABI 小执行的块 0 与 19 各有 443 个载荷及 95614 对必需前提；新计划
删除 2188 对且不新增，超额由 2259 降为 71。每种 SET/WAIT 由 1772 降为 408，
屏障由 444 降为 31，检查 372 次因果复用。重方向使用 ID 0–5。
这是有限主机模型证据，不是统一支配、最少 ID 或设备加速声明。

研究检查器原先保留多个展开图及重复字节集合导致内存不足。现仅保留一个命令
分支、共享完全相等的不可变字节集合，并用等价前缀合取节点和精确位集闭包。
独立小图逐事件比较保持检查语义。仍使用原 120 秒监控及 2 GiB 最佳努力 RSS
拒绝机制；研究验证成本与生产构造成本分别报告。运行完整命令见英文文档。
