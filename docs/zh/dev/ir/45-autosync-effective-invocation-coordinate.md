## 提供者拥有的契约

支持的原表达式为：

```text
b = buffer.get_block_idx()
e = (b + r) % B
for i in range(e, stop, B):
    original payload(i)
```

原 INDEX 加法、取余及别名保持类型。常量 `B > 0` 必须等于独立建立的单例实际
launch 数量，全部允许调用者均须提供该数量，完整原 block 域必须正好为 `[0, B-1]`。
仅有 block 索引包络不能证明数量。数量区间、部分 worker 范围或不同数量均拒绝。
生产入口使用已有全调用者证据；显式诊断必须另行提供数量。

旋转量 `r` 是已证明非负范围内、调用内不变的原参数。原 INDEX 加法必须对所有允许
worker 与参数值不溢出。取余不能修复溢出的中间值，不能擦去窄化转换。
命名坐标及支持定义必须支配载荷树。同名不等于同一 SSA，外来循环变量或参数不能获证。

固定任一允许 `r` 后，加 `r` 再模 `B` 是 `[0, B-1]` 上的双射，逆映射为减 `r` 再模 `B`。
因此每个原 worker 对应唯一有效坐标，每个有效坐标均覆盖，而无需枚举 worker 或参数值。
非负和原算术检查证明实际取余含义，而不只是抽象置换。

`SyncInvocationCoordinate` 不可变，仅能由 `Qualify` 构造。它保留原函数、表达式、定义、
参数契约、独立数量及支持身份。导入拒绝外来 owner 或不同参数／case 契约。
这是一类合格坐标，不是一般符号逆变换或地址 swizzle 构造。

## 分析与可执行消费者

激活分区和已放置访问坐标图以 `e` 为数值分析坐标，拒绝把其他原 block 使用误当成 `e`。
每个完整区间仍须资格确认；一个成功代表不构成完整调用结果。

原载荷表达式、循环 IV、起点、守卫、重置身份及参数 SSA 保持不变。逻辑 case 守卫与
已分配命令调度在合法 cut 使用**原命名 `e` 表达式**。结构化解析器保留同一坐标 owner。
降低消费实际逻辑 token 与独立数量，不依据访问重新构造另一个 token 计划。

公开 case 选择接受原 worker 与实际原参数值，再应用合格映射。存储边界查询也映射并
验证原值。缺失、越界或选错 case 的值返回不可用，不猜测代表 worker，不伪报空选择器。
保存／重解析的逻辑程序通过已有全调用者证据及原定义重建契约，不依赖分离的 sidecar。

同步协议、分配着色、资源预算及硬件豁免不变。每个候选仍需现有六 ID 检查与命令复用
证明；坐标置换本身不能建立物理分配。

## 构造工作与就绪性

源码索引记录赋值和循环出现位置，不递归遍历无关标量表达式 DAG。一次不可变别名 memo
压缩原单赋值链，供各循环起点和候选操作数共享；循环别名拒绝。此 memo **不是**词法就绪
证明：另一有界遍历按原支配语句前缀检查候选。即使全局索引可解析，未来或嵌套定义仍不可用。

解析区间服务保留现有 node/piece 计数。分区紧凑不意味着后续全部接口和物理工作具有相同
界。测试独立改变 launch 数量与访问次数，保留命名计数而非从一次时间推断复杂度。

## 独立资格与当前状态

聚焦夹具保留同一符号配方并使用原 block／旋转值。独立解释器从原程序提取实际字节访问，
比较实际保留 covers、四种事件查询与首末存储边界。物理解释器检查实际发射命令的需求覆盖、
匹配、无环及消费先于重发，并使用显式可用 ID。

已通过的聚焦门覆盖：

- launch 8 与 24、活动和空 worker、旋转 0、1 与 `B-1`。
- `B=8`、stop 9／16／19 的多次访问、复用及最后短轨道，使用同一保留分配。
- 公开 Insert/Optimize/Lower、序列化、原循环身份和独立调用者数量收集。
- 缺失／不匹配数量、未知调用者、多调用者不同数量、无关 block、外来身份、窄化和溢出。
- 512 别名／512 循环与无关深度 28 共享 Boolean DAG；循环别名和未来定义仍拒绝。
- launch 8、24、1024 的同一双 case 结构保留相同 node/piece 数，仅度量分区工作。
