# Qwen prefill 流水线里程碑

起始实现：`62ab48ed54325ee3cddfdb8b8579410aaa87d108`。
本工作扩展[缓冲流水线检查点](17-buffered-pipeline-checkpoint.md)，目标是
PyPTO-lib prefill 中完整的输出投影和组合 gate/up 投影计算体，并明确调用者契约。
这不表示整个 Qwen 模型或注意力计算体已获得资格。

每个里程碑都必须先通过架构、正确性和算法/性能三项独立评审，才能开始下一阶段。
检查点记录将保存评审意见和准确的源码身份。

| 里程碑 | 实现与验收 |
| ------ | ---------- |
| 1. 输入 | 固定原始计算体和配置；保留调用者、启动、访问、守卫及原始坐标证据。未知范围保持不可用。独立检查输出与 gate/up 活跃工作块。 |
| 2. 常驻缓冲与嵌套阶段 | 将现有叶节点和合并服务推广到序列/重复结构，保留初始化及累加器重置。完整写入冲突类与精确物理点选择器分离。检查实际覆盖边及四种事件查询。 |
| 3. 跨区导出 | 不展开 K，导出原始作用域中的发生身份和选择器。数值长度优先使用现有数值接口；仅在满足前提且有必要时实现区间/模运算算法。 |
| 4. 物理传递 | 通过现有分配和发射服务使用作用域需求族；检查匹配、切入点、方向 ID 和因果复用。不改变分配策略。 |
| 5. 资格检查 | 原始输出和组合 gate/up 均通过生产可选路径与 C++ 生成；独立有限语义检查、几何规模测试和可复现远程设备矩阵。 |

输出投影先装载两组 A/B 操作数，再执行两个内部提取/累加循环。每次 L1 装载
只为本组首个读取提供就绪条件；最后的 MTE1 读取释放该存储。不能自动用第二组
最后的装载阻塞第一组。累加器跨两个内部循环及所有 K 对保持常驻。

输出调度为 20 个块启动 20 个工作块。Gate/up 为每个投影的 17 个块启动 24 个
工作块，并保留起始轮转和 up 偏移。两个循环分别执行零次或一次；跳过阶段不刷新
存储，也不重置通知资源。

`placed_sync_import.cpp` 当前只连接直接调用点的范围。阶段 1 将通过有索引的
无环调用图传播已证明范围，在访问被调用者前合并所有调用者。递归或未知证据保持
未证明。启动坐标独立于形参索引；向 JIT 传入标量样本不构成范围证明。

保留标量和已获资格的累加器硬件规则、六 ID 预算、事务式 PTOAS 委托及零内部
循环行为。建模需求精确性、原始访问资格、顺序保持、物理复用和原生调用完成是
不同的保证；主机里程碑不建立设备结果。

当前状态：里程碑 1 进行中；尚无新的里程碑获批。

## 里程碑 1 证据

固定 PyPTO-lib 源码版本为 `f2c80074c0b06ab5bf87fc2bfb06db417fcd35f1`。

原始 AST 等价检查。独立调用的输入就绪是显式契约，不能从采样值推断。
配置调用者循环遍历两层，权重明确声明 `2*HIDDEN` 行；worker 的 ABI 第 3
项是范围 `[0,1]` 的层索引。输出和 gate/up 分别保留原始 20、24 worker
启动；未知启动或不支持的直接 AIC 调用使证据不可用。四个 band 分别作为
明确配置；未配置运行时 band 保持未证明。不同 GM 参数的互不别名仍需显式契约。

中的全部 24 个 gate/up worker，以及首末层。另有 12 个 hidden=512 的小规模
布局执行独立枚举访问集合，覆盖 band 0/3 和层 1/0。这些是输入检查，不是
新嵌套核的最小覆盖、匹配或物理分配证明。原生指令足迹及调用完成仍未独立验证。

hidden 为 1024、5120、51200 时，输出调用证明均保留 3 个函数、2 条边、
156 次图索引表达式访问、180 次范围遍历表达式访问、45 次范围查询；gate/up

## 里程碑 2：已支持的数值 resident/嵌套组合

M2 在现有有限/周期叶分析与数值合并之上保留原始 Sequence/Repeat 树。
源路径保存原始循环、起点、步长和重置坐标；共享摘要不代替源操作身份。
移动读取仅在完整写入冲突类成员关系不变时接受。组合使用冲突类边界，
点查询则独立求解内层成员区间，并通过外层重复提升首末坐标。

结构化周期叶复用现有逐管线 core-frontier 构造，不再保留旧的二次规模
全事件距离表。源路径使用 push/pop 遍历，仅复制最终叶坐标。数值合并的
成本按提供的端口和存储接口计费，不声称大的物理分区也是线性或免费的。

初始化目前支持单叶循环或直接父/叶两层。原始首访条件、操作数和分支调用
保持不变。首次访问证明覆盖整个父体及物理别名；后续访问使用独立、不可变
的入口证明视图并共享内部数学结果。首次访问及外层重置仍保留初始化语义。
空区域不能提供入口证明。既有累加器保护仍要求相邻、合格、同一累加器的
M 边界且中间无读取（包括 FIX）；不会制造完成到开始的隐式边。
更多中间重复层的初始化仍明确拒绝，因为缺少各中间接缝的延续证明。

评审发现并修复了空后代错误提供初始化证明的问题；缺少中间接缝证明的情况
现在明确拒绝。独立原始 IR oracle 检查具体模型访问、展开的实际保留 covers、
闭包、四种事件查询和存储选择器。它共享声明的指令/布局模型，不共享编译器
的分区或生成边；这是主机验证，不是原生硬件资格证明。

串行聚焦测试 **318/318** 通过，保留 11 个上游 inline 方向标注警告。覆盖
交错填充、嵌套切片读取、累加器初始化/延续、FIX 干扰、空访问和外层重置。
新的源树物理导出仍明确拒绝；既有嵌套物理/C++ 路径继续受测试保护。

## 里程碑 3：作用域导出与调用激活

M3 在原始 `CompactSyncResult` 下缓存不可变需求模式。模式保留原始端点、
具名循环轴以及源端和目标端各自的展平步长。顺序区域导出已有跨区需求，
重复区域导出子体和一个相邻访问接缝；遍历源定义，不展开二进制重复 DAG
的全部使用。空子区域保持透明。导出不重新归约，也不按 K 展开。
旧的有限物理适配器在 M4 完成前仍明确拒绝这些模式。

正确性依据是连续原始子区域的内部覆盖仍然成立，已有合并提供归约后的
跨区覆盖。均匀重复具有相同内部和退出关系，启动仅改变入口资格，因此
相邻子体接缝可代表全部合格相邻访问。独立测试将模式展开为原始出现对，
同时比较保留 DAG 与由原始访问重新构造的最小覆盖。

启动坐标与形式参数和循环序号分离。符号起点的单次循环保留实际起点，
规范化序号零不能证明原始 `iv==0`。存储平移以已证明分区的 block 下界
为原点；缺少绑定时选择器不可用，其他有效局部查询继续保留。

`SyncInvocationAnalysis` 使用浅层调用分区，在原始类型上检查每个算术
中间值，并在已证明的单位步长单周期模域上按回绕和零/一次访问边界分割。
偏移必须为常数或明确证明为固定值的参数。所有非空分区必须成功，才发布
完整所有者。查询验证全部调用界限；原始 IR 与坐标身份共享。无活跃载荷
的分区表示已证明缺席。非单位步长、多周期和未固定偏移仍不可用。

成本按分区计费，包括坐标片段及各分区的导入、归约和接口构造，不宣称
对源 IR 普遍线性。模式大小取决于接口和坐标深度，而非访问次数展开。
物理使用方必须保留准确分区所有者；分区互斥不构成跨调用 ID 复用证明。

使用 `qualify_qwen_prefill --crossings` 进行 M3 验证。最终结果及审查结论
将在完成后记录。匹配、物理分配和完整 Qwen 同步代码生成仍属于 M4/M5。

M3 定向测试 **372/372** 通过。最终验证覆盖每个激活区间两端的 **34** 个小型
原始布局执行：2,226 个载荷/访问实例、1,436 条实际保留覆盖、696,632 个事件
查询及 3,240 个存储选择器，均与独立参考一致。包含 gate/up 同时活跃、跳过
阶段、全部四个配置 band 和两个 layer 极值；不构成本地指令或统一实现证明。

完整 output 使用一个分区，gate/up 使用三或四个。hidden 1,024→5,120 时，
output 保持 41 个分析出现和 17 个模式；gate/up 各 band 合计保持 164–246 个
出现、73–112 个模式。独立 outer/replay 次数 2→1,000,000 时，保持 14 个
出现、12 个模式和 17 个轴条目，合并节点 4→52。分区复制与接口成本单独计费，
约 0.6–4 ms 的分析时间仅为描述性测量。

独立参考每例约 5–15 秒，明显大于生产分析。累计 240 秒 watchdog 在完成
32 例后中断参考验证；确认生产源码、输入、扩展和参考校验器哈希一致后，
在相同 watchdog 下续跑剩余检查，未扩大编译超时。测试参考仅以等价布尔
判断避免临时读写集合并集，不改变保护语义。原定向测试与最终验证分别记录
在 `18-qwen-prefill-m3.json`。M3 未改变 flag、barrier、分配策略或硬件豁免；
原物理路径仍明确拒绝尚未支持的共享重复作用域。

## 里程碑 4：原始作用域中的物理实现

适配器消费 M3 缓存的、由提供方拥有的需求族，保持原始坐标、逻辑记录身份和插入位置。
常量物理 ID 不会消除逻辑坐标。沿用六 ID 方向资源池与现有 whole-span 分配算法。
只有 `PhysicalSyncInvocation.function` 是可执行程序；各 case 保存分配和插入证据，
其 function 字段为空。

周期一复用证书要求端点使用相同的原始外层坐标前缀、精确混合基数步长和矩形活动域，
仅最内层轴可平移或截断。每种进位检查前一消费者完成到下一生产者启动的可达性。
其他实例由不变主体和接缝关系平移得到；前向路径不能离开连续区间后返回，
因此不能借用区间外的初始化边。进位查询及后缀计算为 O(depth)，
查询本身的图代价另计。按原始顺序排序的坐标开销为 O(F log F * depth)。
这是充分证书，不是最优着色证明。

M/V 同管线需求还必须满足相邻活动原生事件条件；公共坐标保证原生秩差不变。
非相邻屏障、DMA/FIX 屏障继续拒绝，标量屏障禁止，现有硬件豁免不变。
所有 case 的分配成功后，使用原始且支配插入位置的 block-index 值保护命令，
通过一次原始 IR 遍历插入。初始化分支和负载不按 case 复制。
case 互斥仅证明同一调用内资源共享，不增加原生入口/返回保证。

独立命令图检查覆盖进位、K=3/4/5、空/单次循环、重置、活动边界和初始化/累加分支，
验证负载顺序相等、匹配、无环、通知闭合和消费后再发布。
嵌套 Vec 正/负例分别接受相邻屏障并拒绝非相邻屏障；缺少支配绑定时保留原 IR 与数学结果。
完整 gate/up 程序验证 band 0/3 的全部活动区间边界。

完整 output 为 17 SET + 17 WAIT，无屏障；gate/up band 0/1/2/3 分别为
73/90/112/90 SET 及相同 WAIT 数，含互斥 case 的全部静态站点，不能当成执行次数。
K 与 replay 从 3 增至一百万，保留 31 分析实例、17 SET、17 WAIT、22 guard、29 进位查询；
merge 数从 6 增至 58。重复物理请求不重做进位证明。
15 个原布局测量的分析为 0.55–4.67 ms，物理构造为 0.18–1.14 ms，均为描述性单次测量。
两个完整投影的诊断 C++ 生成成功，PTOAS 0.72 autosync 开/关输出逐字节相同。

部分通用嵌套例仍因 whole-span 充分预留需要七 lane 而拒绝，这不是六 ID 不可行证明。
当前接纳的不变结构提供方尚无触发周期一防御性拒绝的反例；没有伪造可变模式或混淆更早的导出拒绝。
缺失证书仍为未证明；原生入口/返回和设备执行仍未建立。
复现：使用上述环境执行 `python -m tests.ut.ir.transforms.qualify_qwen_physical --output build-py314/qwen-prefill-m4`。
JSON 固定脏源码、扩展、输入及工具。M5 将独立验证普通 opt-in 生产调度。

M4 扩展门禁首次为 535/539；四个序列化/独立编译检查触发测试 oracle 的 Var/名称比较异常。
经审查的修复保持 SSA 身份优先，身份变化时仅接受唯一活动名称。三个受影响文件重跑 128/128，
四个失败全部解决，聚合为 539/539；不是一次全绿重跑，保留两次记录。三类审查均接受 M4。

## 里程碑 5：普通生产路径验证

闭合程序提供 launch 范围时，`RealizeSync` 使用完整 invocation owner；没有该证据时
保持原直接路径。全部 case 成功后才发布完整内核，空标记或拒绝时保留原函数交由 PTOAS。
默认仍关闭 PyPTO autosync，两种模式均保持 PTOAS autosync 开启，不按内核名称识别。

对原始标量 SSA DAG 做记忆化依赖查询。与 block 无关的循环起点仍使用导入器的完整
范围、就绪和次数证明，不要求无关的有界参数变成常量。通用 AIC/SPMD 回归验证实际
调用/launch 条件下的常量和参数 singleton 循环。混合 block 与非固定标量的起点仍受
固定偏移 partition 契约限制；部分可由直接导入器证明均匀单次的输入会保守委托，
这是剩余选择能力问题，不是错误同步接受。

完整 output 和四个 band 的完整合并 gate/up，通过普通 `.compile()` 选择 PyPTO。
五种配置分别开/关 PyPTO，共十次 C++ 生成均成功；开启模式报告 PyPTO，PTOAS 保持开启。
这是固定调用适配下的原始投影主体，不是整个 Qwen prefill 模型。单次完整编译 88–148 ms，
其中 RealizeSync output 1.09 ms、gate/up 3.67–5.28 ms，仅为描述性主机测量。
最终门禁与审查见 `18-qwen-prefill-m5.json`。

设备任务是 `pypto3_sync_more` 顶层本地文件，不进入分支。需传输精确源码快照
（当前未提交）、验证两个同步所有者模式、数值结果并交错测量设备内核时间。
此处不声称设备结果。
