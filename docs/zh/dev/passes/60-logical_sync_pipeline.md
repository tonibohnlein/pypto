# 逻辑同步阶段（实验性）

`insert_sync`、`optimize_sync` 和 `lower_sync` 将最小需求分析、逻辑完成令牌
（completion token）和物理事件分配分开。它们在物理地址分配及 Buffer 降低后
显式调用，不改变默认编译流程。

```python
from pypto import passes

with passes.PassContext([], autosync_disjoint_gm=True):
    logical = passes.insert_sync()(placed_program)
    logical = passes.optimize_sync()(logical)
    physical = passes.lower_sync()(logical)
```

`autosync_disjoint_gm=True` 是调用者提供的不同 GM 参数分配互不重叠的契约。
`InsertSync` 复用现有访问导入器、最小需求分析及原始坐标令牌导出。
现支持单区域旋转槽流的常量距离历史；有限数值跨区域导出使用 occurrence capture；满足条件的常量嵌套区域也支持逻辑插入，
并可通过下述作用域数值证书限定物理降低。`OptimizeSync` 验证后原样返回。

`LowerSync` 首先支持直线有限令牌程序：record、completed、join 和 wait。
它解释实际令牌定义及使用，不重新分析存储来替换手写依赖。记录包含该管线
此前导入的等待。令牌不消耗，多次使用必须分别建立匹配的物理交接。
物理 ID 复用要求证明先前消费到后续发布的因果路径。它复用现有资源目录、
原生保留 ID 及通道着色算法。控制流或同管线放置证明不足时明确拒绝，不能
把这些拒绝视为物理容量不足。

有限直线程序中，每条管线的等待构成有序链。分析为每个事件保留各管线
可达的最大等待序号，并分别传播开始、完成和等待状态。记录合并完成状态
及此前导入的等待。同管线记录的前缀单调，因此 join 等于最新前缀。
只有前一消费的序号可达后一发布时才复用 ID。这为现有生命周期着色算法
提供有序后缀关系；最小性仅针对所选逐使用交接方案，不针对所有令牌实现。

共享表达式按不同节点缓存，嵌套语句序列只收集一次。访问恢复仍使用原有
导入器，其限制及成本单独计入；当前独立降低尚未传递调用者参数范围证据。

结构化降低现在支持规范的常量距离循环：记录紧随原始负载（或完整初始化/
累加分支），等待位于目标负载之前。循环携带值必须从 completed 开始，且
每次无条件同时移位。距离 d 的守卫为 `iv > start + (d-1)*step`；三访问历史
yield `[current, previous_1, previous_2]`。解析按变量身份沿历史方程查找当前
记录，拒绝循环或外部调用历史。只有第一历史输出选择最后源访问；非空旧
结果不能冒充最终边界。进入另一个循环时使用精确原始坐标相等守卫。零次循环输出仍为
completed。原始起点、正步长、类型及计数由既有导入器验证。

实际令牌使用逐一成为交接族，不重新提取存储覆盖边。周期前沿由这些边
构造，既有分配器和发射器复用。消费负载完成到下一发布负载开始的路径
提供充分复用证明；此路径不能证明最少 ID。累加器存储转发不会被提升为
完成到开始的事件顺序。

单区间不构造边界图；多区间共享既有首/末端口图，其构造对端口数可能是
二次的，跨区间查询为 `O(P+E)` 图遍历加子查询。周期核心成本为
`O(k(m+u) log(m+u))`，不枚举循环次数。未经作用域证书限定的嵌套令牌、任意结构化 join、非空
入口事实、循环历史、非空旧结果跨界及非规范守卫仍明确拒绝。

标量历史大小 H 是各源最大活动距离之和。插入产生 O(H) 个携带/结果/yield
节点，无活动使用的历史不构造。遍历为 `O((N+F+H) log(N+F+H))`；
解析迭代执行并缓存，不消耗与历史深度成比例的调用栈。固定距离时表示不随
循环次数增长，但不声称对二进制编码周期紧凑。

完整降低并存在 SET/WAIT 后，复用既有物理所有权属性告知 Buffer 代码生成。
该属性表示所给令牌协议的所有权，不证明手写令牌覆盖所有存储需求。空计划
不伪造标记，委托槽选择及原生多缓冲区大小限制保持不变。

迁移完成前 `realize_sync()` 保留原生产路径。最终将成为三个阶段的事务式
协调器，保持原有启用开关及整核 PTOAS 委托。逻辑匹配和物理复用不证明
异步负载在函数返回时已完成；原生语义和设备验证仍是独立义务。

完整的当前支持范围见[英文契约](../../../en/dev/passes/60-logical_sync_pipeline.md)。

## 数值出现捕获（occurrence capture）

内部源访问 v 用一个 completed 初始化的携带值保存：在
`iv == start + v*step` 时选择当前记录，否则保留同一携带值，最终循环结果
即所选完成事实。每个源出现仅保留一个捕获，不构造从 v 到循环末尾的完整历史。
多个消费者共享捕获状态，但物理交接仍逐使用分开。

降低检查纯令牌 yield 分支、同一携带值、管线、调用与原始坐标。捕获只能通过
循环结果使用；中间状态不可导出。证明未执行的出现输出 completed，不能把
缺失存储导出当作空访问。消费者 w 使用 `iv == start + w*step`。

所有实际跨越端点在构造子区域顺序链接前注册为边界端口。连续且参考向前的
区域路径由内部链接、跨越及原生边界组成，不能离开子区域后再返回。状态大小
为 `O(H+B)`（历史 H、捕获 B）；端口链接仍按扩大的端口数计二次成本。导出
可能枚举槽或行，不声称任意接口都紧凑。没有新增令牌操作或分配算法。

## 嵌套作用域的逻辑插入

原始区域树可通过已有笛卡尔需求族进行逻辑插入。
端点保留原始循环身份和混合基数坐标；变化轴必须是共同的外层前缀，步幅与范围精确匹配。
当前支持共同变化轴上的相邻访问连接，不支持更长距离或没有外层连接的固定坐标差异。

来源完成事实逐层退出内层循环：末次访问直接 yield，内部指定访问使用纯 token 条件选择。
每层 carry 在其实际调用入口初始化为 completed。
相邻外层连接再把选定事实传到下一次外层访问，因此内层计数器可以重置。
消费者使用精确的原始笛卡尔条件，记录仍位于完整负载宏之后。
共享的是不可消费的完成事实，不是物理 flag 身份。

F 个需求族、D 层循环新增 `O(FD)` 状态和条件节点，不展开行数或循环次数。
上游导出成本单独计算；动态起点仍显式拒绝，并保留数学结果。
逻辑插入本身不证明物理复用；下述独立作用域数值证书限定嵌套 `LowerSync`。

[作用域插入回执](../../../en/dev/ir/token-pipeline-m3b.json)记录了 29 项针对性检查、
1,148 项广泛回归及重新构建后的 150 项 token 回归。
行数或访问次数增至一百万时，测试的嵌套集体填充仍只有两个 record、三个 wait 和四个 carry。
数值摘要仍需对数规模的重复合并。单次主机时间仅作描述，不构成加速结论。

## 作用域令牌使用解释检查点

诊断接口 `testing.inspect_scoped_token_families` 在显式 GM 不相交测试契约下，
验证逻辑 SSA，移除已限定的纯令牌结构，并通过已有 placed Buffer 导入器保留
原始载荷与循环坐标。它解释实际 SSA 使用，不重新生成存储需求，也不分配物理 ID。

令牌模式的有效域恰好表示非 completed 的执行域。completed 初始化、同时更新的
循环携带值和保留自身携带值的纯捕获建立这个不变量。因此，与 WAIT 条件取交集
只会消去等待 completed 的使用。条件必须是活动原始坐标上的精确矩形区间。
重复 WAIT 保持独立交接；无法表示为公共前缀单射族的扇出、中间捕获使用及偏离
合法插入位置的命令仍被拒绝。

一元方程解析使用迭代和记忆化。T 个方程、U 个使用和深度 D 对应 `O(TD)`
模式存储/复制及索引开销，族构造为 `O(UD log(D+2))`。作用域检查访问 D 个
框架；条件遍历按每个条件计费，包括共享条件的重复使用和嵌套域映射复制。
不展开迭代次数，也不声称整个条件 DAG 只遍历一次。导入与验证费用独立计入。

解析成功不证明平移不变的重复顺序或物理复用。该解释检查点本身不启用嵌套 LowerSync；后续数值顺序证书提供单独的物理限定。
独立测试将展开后的实际使用多重集与 SSA 执行逐一比较，覆盖修改后的捕获、
缩小或移除的条件、completed 入口、重复 WAIT、序列化和计数器复位。
详见[机器可读记录](../../../en/dev/ir/token-pipeline-m3c.json)。

## 作用域数值顺序与复用

`LowerSync` 现在可将具备原始区域树的常量嵌套令牌程序送入共享的数值顺序服务及
原有物理分配/发射器。该路径不重新提取存储冲突或最小需求。

证明子图只包含在所属命名循环层级中始终活动的体内边和相邻原始循环体接缝。
祖先域必须完整；固定内部后缀坐标在计数器复位后仍保持原意。仅首次、末次或
其他裁剪域的边仍保留为实际交接义务，但不扩张为统一复用证据。查询成功证明
实际顺序；失败仅表示当前子图无法证明，而非实际程序不存在该顺序。

每次组合保留原生启动/启动、完成/完成链接以及所有跨越端口。二进制重复始终
在相邻原始循环体间平移接缝。缓存归属于不可变的体/接缝所有者，并包含次数和
所需相对端口；相同大小的不同复位体不能误用彼此的证据。累加器访问保护不被
转换为完成到启动的事件边。

每种混合基数进位类别通过一个代表查询证明相邻交接的消费先于再次发布。
证明路径中的边在相应命名层级上统一，且参考顺序向前的路径不能离开连续子区
后返回，因此代表路径可平移到该类别的所有成员。裁剪交接也可利用这种统一
子图证据；它本身无需作为证明边。相同流水线屏障仍独立检查完整载荷调度中的
直接原生前驱。证明失败保留拒绝，不宣称物理容量不足。

所有实际交接（包括重复使用和例外边）进入未更改的分配器；不删除命令来满足
容量或证明限制。所有者覆盖分配和发射阶段，查询回调借用其生命周期。默认
`RealizeSync` 分派保持不变。

数值摘要深度随次数的对数增长。B 个具体外部端口沿 `O(B log K)` 路径传播；
符号交接族不展开为 K 个端口。行组合、端口集合复制/比较、坐标路径和叶查询
成本分别计入。计数器记录不同的非空摘要节点和行条目，不重复计算缓存别名，
也不等同于全部内存字节数。

独立有限检查覆盖证明子图的四类事件查询、对实际 SSA 顺序的包含关系、所有
接受的复用/屏障证书，以及实际物理命令的匹配、因果复用和六 ID 合规性。
序列化和 C++ 生成另行验证。扩大到 1,048,575 行或访问时仍为三个 SET、三个
WAIT 和 24–26 个算术站点。单次时间仅为描述性数据，未进行设备验证。
[记录](../../../en/dev/ir/token-pipeline-m3d.json) 保留范围与限制。

DMA 同流水线机制、动态原始循环界限、一般非矩形条件及独立调用者/块范围证据
仍有明确限制。驻留缓冲区复位和零内层程序不会为通过物理阶段而删除逻辑顺序。
