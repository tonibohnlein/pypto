# Eventful retained children in conservative prefix parents

This checkpoint extends the explicit child-provider interface. A local counted
region can retain its compact exact token recipe inside a parent whose control
is not admitted by the numerical exact importer. Default dispatch is unchanged.
The initial family does not qualify the load-bearing Qwen K region: its external
reads and free address coordinates require a separately qualified projection.

## Provider and ownership

`prepare_eventful_sync_children(original, scopes)` makes one original-owner
statement/definition index for the whole request. Each requested scope retains
its original nodes, ancestor frames, dominating signal-free bindings and one
immutable numerical analysis. Only required bindings are included in the
regional mathematical request. Their dependencies are checked at their own
original use cuts. The binding owner owns the mathematics; the original context
certifies its relation to the parent. Neither owner is replaced by a sampled or
specialized invocation. Requested scopes must be unique and nonoverlapping.

The initial family admits local storage effects, static internal counted frames
and qualified native operations without hidden notification claims. Physical
aliases between different local descriptors remain aliases. It refuses free
caller/enclosing coordinates, including type metadata, and external effects.
The conservative parent does not acquire a disjoint-GM premise from the child.
Missing exact selectors remain unavailable; none are fabricated for composition.
The whole request publishes handles atomically or refuses without changing IR.

The shared index costs one traversal of the original statement tree. Queries
walk their scopes, ancestors and required bindings; static binding qualification
is cached within that request only. `describe()` reads retained costs without
running recognition or constructing exports. Its shared index size is counted
once per batch, not summed over children. This removes the earlier repeated
whole-owner scans; it does not claim constant export cost or a whole-compiler
linear bound.

## Composition and validity

The parent retains all possibly pending child effects, separated by pipe and
read/write mode through the existing conservative effect classes. Notification
closure never kills payload effects. Existing no-KILL transfer, service pruning
and allocation algorithms are unchanged.

For every ordered pair of participating pipes, entry includes a closed service:

```text
record(p); wait(q); record(q); wait(p)
```

All entry services are controlled by the same original child-invocation guard
and precede that invocation on its participating pipes. Their logical effects
are explicit before physical allocation. Arbitrary child commands remain outside
parent service pruning.

For a child flag `p -> q`, the previous consumption on `q` precedes the entry
publication `q -> p`; its acquisition on `p` precedes the next child publication.
This proves consumption before republication across visits, counter resets,
skips, and transitions between different qualified children. The wrapper makes
a common private palette sound across those children; taking a maximum child
budget without this wrapper proof would not suffice.

Parent roles are assigned through the existing directional eligibility and
native-reservation interfaces. Child lowering receives a common eligible palette
excluding every reserved parent role ID. This conservative intersection can
refuse an otherwise feasible directional assignment. It is not a new coloring
algorithm or a capacity lower bound. Missing directions, insufficient resources
and missing matching/frame evidence remain separate refusals.

`LowerSync` parses the actual token program again, including serialized input.
The versioned child marker routes parsing and provides no proof. It reconstructs
lexical bindings and the union of payload pipes, record sources and wait
destinations. Thus command-only services cannot hide resource participation.
It validates entry acknowledgments and lowers the unmarked child
through the existing scoped-token parser, matching decoder and allocator. A
child's original command cuts and internal order are preserved. On embedding,
each SET includes earlier parent waits on its source pipe, exactly as its logical
record does. Thus the within-child proof is stable under extension by those
prior prefixes. Closed matching establishes neither child-exit payload completion
nor invocation completion; the existing final-boundary mechanism remains separate.

Fresh completion SSA names come from the parent's naming owner. Payload variables,
original induction variables, storage descriptors, guards and coordinate
identities are retained. Failed preparation or lowering publishes no partial
physical program or resource claim.

## Reproduction and evidence

The focused module is `tests/ut/ir/transforms/test_eventful_sync_children.py`.
It exercises an irregular symbolic parent with accesses before and after its
child, shared local bytes, zero/one/multiple visits, conditional skips and inner
counter resets. Separate checks cover original-owner transplant refusal,
unavailable enclosing coordinates, complete missing-entry services, insufficient
eligible resources, serialized actual tokens, shared child palettes and naming,
and retained size as K and the static child count vary.

The reusable qualification entry point is:

```bash
PYTHONPATH=python:tests/ut/ir python -m transforms.qualify_eventful_sync_children \
  --output build-py314/eventful-child-20261115/qualification-accepted
```

It compares the previous primitive conservative-prefix policy with the same
policy importing the child. Independent interpreters recover physical bytes and
actual logical/physical command graphs. The concrete reference adds access
hazards to the native event graph, with the existing independently checked Cube
accumulator exemption. It checks coverage, matching, acyclicity and causal reuse,
then reports full completion-to-start relation differences in both directions,
excess prerequisites, and static/executed command counts separately. No dominance
or speedup follows from a count reduction alone. Single-run stage times are
descriptive; inclusive times must not be added together. Large K checks inspect
retained state only; the bounded oracle may unfold its small test instances.

The final integrated gate passes 183 tests, including all 16 focused child tests;
all configured hooks, including full pyright, pass. The bounded same-policy
comparison has no added completion-to-start pairs on
its 18 executions. At K=3 with three visits, it removes nine pairs; excess falls
from 32 to 23, executed SET/WAIT counts each fall from 180 to 111, and barriers
fall from 46 to 25. This finite relation containment is stronger evidence than
comparing only command totals. It is not a uniform dominance theorem. With K=0,
three taken visits retain the same payload order while entry overhead raises
SET/WAIT counts each from 72 to 96 and barriers from 19 to 25.

For K=2/17/1023/1,000,000, retained counts stay at nine analyzed occurrences,
five cells, one region, six scope nodes and five bindings. These are production
request counters, not oracle unfolding. For 1/2/4/8 static children, source-index
nodes are 24/30/42/66 and summed query-scope nodes are 6/12/24/48. Source generation
also succeeds through the pinned PTOAS path. The machine-readable receipt
records tool/source and artifact hashes. No device execution or native
cache-visibility qualification is implied by these host-model checks.

## Paper consequences

| Established construction | Remaining premise or limitation | Appropriate claim |
| ------------------------ | ------------------------------- | ----------------- |
| Original-context local numerical child retained in an irregular conservative parent | Only the stated local/static provider family | Exact internal demands can coexist with conservative parent services. |
| Explicit entry acknowledgment plus disjoint parent/private palettes | Existing direction, native-resource, matching and allocator qualifications must all succeed | Closed child notifications can be rearmed uniformly across visits without completing its payload at child exit. |
| Actual-token reconstruction and independent emitted-command checks | Bounded checks do not replace the uniform wrapper argument or native qualification | Lowering preserves the supplied selected parent order within the admitted host model. |
| Shared original-owner index and trip-count-independent retained child sizes | Export/interface work and later compilation remain separately charged | Numerical compactness is preserved for the demonstrated family, without claiming a universal composition bound. |
| External reads remain refused by this first family | Role-sensitive readiness and explicit incomplete-GM export coverage are still required | This checkpoint does not establish whole-Qwen exactness or general external-storage child import. |
